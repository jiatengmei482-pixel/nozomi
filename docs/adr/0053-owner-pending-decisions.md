# ADR 0053：落定各 ADR 里待负责人确认的决定

- 状态：已采纳（2026-11-01）
- 补充 ADR 0034、0040、0042、0044、0049、0050、0051。

## 背景

负责人 2026-11-01 指示：不再参与中间过程，只接受最终结果。需要取舍的地方按推荐方案（安全、保守、可回退）直接做，并写明决定和理由。只有必须他本人动手的事才列进最终待办。

这几篇 ADR 里还有标着「待负责人确认」的项。它们此前已按推荐实现，本文把它们定下来，让后面的人不用再等。负责人没有逐条审过这些决定，他之后可以改；每条都写了怎么改。

## 决定

没有单独说明的，一律**维持现在的做法**。原文的理由继续有效，不在这里重复。

## 验收的边界

负责人不参与中间过程，不等于没验证的事可以算通过。

- 依赖他本人才能验证的任务（M4-06、M4-08、M4-14 的真实收件）保持「待验收」，列进最终待办。
- 自己不批准双人复核，包括不用新建账号来批。所以需要第二位财务的流程（收款账户启用、转账文件生成）在测试环境只验到复核之前，后面靠 CI 的端到端测试。
- 不动负责人的真实账号和商品（M3-06 经他同意的测试单除外），不碰正式环境的真实收款。

## 后果

- 上面这些决定他都没有逐条看过，最终交付时要把这篇文档交给他。
- 待办清单里的事不做完，相应任务不能标「已验收」。

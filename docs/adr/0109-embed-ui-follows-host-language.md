# ADR 0109：嵌入入口和嵌入页外层的界面语言跟随宿主页（兜底英文）

- 状态：已采纳（2026-11-25，M12-01）
- 依据：业主 2026-11-25（#288，监工转达）：嵌入入口小程序和嵌入页外层**跟随宿主页语言**，取代同日稍早的「统一中文」（本篇初稿，未合并）。
- **修改** ADR 0095 第四节第 3 小节「多语言」：嵌入入口和嵌入页选语言的规则由「`lang` 参数，不认识的退回嵌入码的默认语言」改为下面第 1 条；该节其余决定（语言类型、按语言分的文案表、`lang` 参数的写法和校验、postMessage 协议）不变。
- 补充 ADR 0108：嵌入组件的地址提示、取坐标带的 `lang`（页面语言）就是下面定下的语言。

## 问题

嵌入入口小程序（`widget-ui.ts`、`widget-booking.ts`）和嵌入预订页外层（`EmbedFrame.tsx`、`embed-texts.ts`）原来按 `lang` 参数显示中 / 日 / 英，没传时用嵌入码的默认语言（嵌入页默认日文）。合作网站不传 `lang` 时，界面语言和宿主页对不上。

## 决定

### 1. 界面语言怎么定（`apps/web/src/embed/widget-core.ts` 的 `pickLang`，纯函数）

只支持 `zh`、`ja`、`en`。依次看，前一条有结果就不再往下：

| # | 来源 | 规则 |
| --- | --- | --- |
| ① | 合作网站 `init` / `mountBooking` 传的 `lang` | 只认 `zh` / `ja` / `en` 三个写法（照旧校验），写错的忽略 |
| ② | 宿主页 `<html lang>`（组件在宿主页上运行，读 `document.documentElement.lang`） | 按 BCP 47 取主语言：`zh*` → `zh`（`zh-TW`、`zh-HK` 也归 `zh`，界面是简体）、`ja*` → `ja`、`en*` → `en`；大小写、下划线都认 |
| ③ | 浏览器语言（`navigator.languages` 依次） | 同上，第一个支持的 |
| ④ | 都没有，或都是别的语言（`ko`、`fr`……） | **`en`** |

**兜底用英文**：合作网站的客人多是外国游客，英文最通用。嵌入码后台设的「默认语言」不再参与界面语言（照常保存；接口不带 `lang` 时服务端地址搜索仍用它，但组件现在总会带）。

### 2. 定下的语言一路带下去

- 查价框：全部文案、日期时间和人数的格式、取配置被拒时的「暂时无法使用」；建草稿时草稿里的 `lang`；地址提示、取坐标请求的 `lang`。
- 宿主页上 iframe 的外层（`widget-booking.ts`）：iframe 标题、打不开 / 已过期的提示；**iframe 地址的 `lang`**（以前没传就不带，现在总带）。
- 嵌入页外层（`EmbedFrame.tsx`）：按「地址的 `lang` → 草稿里的语言（旧版组件脚本没带 `lang` 时）→ 浏览器语言 → 英文」定（嵌入页读不到宿主页的 `<html lang>`，也不看主站自己文档的 `<html lang>`）；文案、`<main lang>`、`ready` 消息里的 `lang`。
- **`ready` 的 `lang` = 实际显示的语言**。字段、取值范围不变；宿主那边的 `widget-v1.js` 只用 `ready` 取消 15 秒后备、不读 `lang`，`ready` 也不转给合作网站的 `onEvent`，所以不会破坏宿主。

### 3. 总开关

`packages/domain/src/guest-ui-language.ts` 的 `GUEST_UI_LANGUAGES`（现在 `["zh", "ja", "en"]`）和 `guestUiLanguage()`：上面定下的语言开放了就用它，没开放退回中文。以后要临时收窄某种语言只改这一处。

### 4. 不在本篇范围、保持现状

- **嵌入页里面复用的四步、订单页、付款，和主站 `/book` 一样目前只有中文**；日文、英文宿主页上会出现外层日 / 英、里面中文的混排。要不要翻译待业主决定（监工在 #288 商量），本篇不动。Stripe 付款表单的 `locale` 照旧跟嵌入页语言。
- 邮件 / 通知模板只有中文（`NOTIFICATION_LOCALES = ["zh-CN"]`），不经过这里。
- 主站 `/site/v1/places/*` 不带 `lang`，服务端按 `zh`，和主站中文界面一致。
- 主站、嵌入页都没有语言切换。

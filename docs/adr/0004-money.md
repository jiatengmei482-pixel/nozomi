# ADR 0004：金额、百分比与汇率

- 状态：已采纳（2026-10-07）

## 决定

- 金额：数据库用 `bigint` 存最小货币单位，同一行必有 `currency` 列；接口输出用十进制字符串（如 `"4600.50"`），不用 JSON 数字。
- 百分比：一律用基点整数（1% = 100）。加价、违约金、取消扣款、赔付比例都如此。
- 舍入：四舍五入，0.5 远离零，在每一步结果上执行。实现见 `packages/domain/src/money.ts`。
- 汇率：以免费源的 USD 报价表为输入；跨币种加缓冲（默认 150 基点）；报价时把汇率写进快照，之后的订单、退款、结算都用快照汇率；实际收付款时的差额记「汇兑损益」。

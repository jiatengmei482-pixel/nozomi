# ADR 0002：区域判断在应用层完成

- 状态：已采纳（2026-10-07）

## 背景

报价时要判断上车点 / 下车点落在哪些租户的哪些区域里。区域有圆形和多边形两种，可能带禁行区（洞）。

## 决定

- 区域形状以 GeoJSON（多边形）或「中心点 + 半径」存入 PostgreSQL 的 `jsonb` 字段，同时存外接矩形（四个数字列）用于粗筛。
- 精确判断用 `packages/domain/src/geo.ts` 的纯函数完成，有完整单元测试。
- 暂不依赖 PostGIS 扩展。

## 理由

- 一次报价先按城市和品类筛出少量商品，每个商品的区域数量有限，应用层计算足够快。
- 纯函数可以在任何环境测试，不依赖数据库扩展，部署简单。

## 何时重新评估

单城市区域数量超过 1 万，或报价 P95 因区域判断超过 100 毫秒时，改用 PostGIS，届时新增 ADR。

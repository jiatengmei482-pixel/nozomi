# ADR 0003：多租户隔离

- 状态：已采纳（2026-10-07）

## 决定

- 单数据库、共享表结构；所有租户表带 `tenant_id` 并作为复合索引第一列。
- 租户接口的 `tenant_id` 只从登录令牌读取，数据访问层的每个查询函数都必须显式接收 `tenantId` 参数。
- 在此基础上启用 PostgreSQL 行级安全（RLS）作为第二道防线：每个请求在事务里设置 `app.tenant_id`，策略只放行同租户的行。
- 平台员工的跨租户访问走单独的 `/platform/v1` 接口，并写审计日志。

## 验证

每个租户接口都要有集成测试：租户 A 的令牌访问租户 B 的资源，返回 404（不暴露资源是否存在）。

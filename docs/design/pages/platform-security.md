# 运营后台：账号安全（两步验证、IP 白名单、角色）

M4-05，接口和规则见 ADR 0030。沿用现有组件（登录页的版式、卡片、表格、对话框、多选组合框），没有新令牌。

## 1. 登录的第二步（`SecondFactorPage`）

- **给谁用**：所有平台员工，每次登录。
- **要完成什么**：输完密码后，没绑定过的先绑定验证器；绑定过的输入 6 位动态码（或一个恢复码）。
- **首屏**：和登录页同一张卡片。
  - 绑定：三步说明（装 App → 扫二维码，扫不了手输密钥 → 输入 6 位数字）、二维码（深色模块在浅色底上，四周留白）、按 4 个一组显示的密钥、动态码输入框、「完成绑定」。绑定成功后显示 10 个恢复码（只显示这一次）：「复制」「存成文件」，勾选「我已经把恢复码存好了」后才能「继续」。
  - 输入动态码：一句为什么要输、动态码输入框（数字键盘、浏览器可自动填一次性码）、「验证」、「手机不在身边？用恢复码」切换。用恢复码登录且剩 3 个以下时，进去之前提醒去重新生成。
  - 底部「退出登录」。
- **地址**：不改地址：两步验证完成之前，运营后台的任何地址都显示这一页，完成后就是原来要去的页面（必须先改密码的，接着是修改密码页）。
- **出错**：动态码不对 / 用过了 / 二维码过期 / 尝试太多 / 加密密钥没配置 / 密钥读不出来，各有一句话说下一步怎么办（`lib/mfa-display.ts`）。

## 2. 个人页「账号安全」（`/platform/account/security`）

- 账号菜单里「账号安全」进入（在「修改密码」上面）。
- 一张「两步验证」卡片：状态、绑定时间、剩余恢复码（3 个以下时警告）；「换手机（重新绑定验证器）」「重新生成恢复码」——都先在对话框里输入现在的动态码（或恢复码）确认本人。换手机在对话框里走第 1 节的绑定步骤，确认之前旧的照常可用。
- 没有「关闭两步验证」。

## 3. 平台员工详情（`/platform/settings/staff/{id}`）

- 列表里点姓名进入；列表多一列「两步验证」（已绑定 / 还没绑定）。
- 「账号」卡片：邮箱、姓名、角色、状态、IP 白名单（自己的；没有时显示按角色的；都没有写「不限制」）；超级管理员可「修改」：姓名、角色（内置 + 自建）、IP 白名单（文本框一行一个，保存前逐条指出写错的）。不能改自己的角色。
- 「两步验证」卡片：状态、绑定时间、剩余恢复码；「重置两步验证…」→ 对话框写明要另一位超级管理员在「待审核」里批准、生效后会怎样，可写说明。

## 4. 角色（`/platform/settings/roles`）

- 系统设置里「角色」（`role.read`）。列表：角色（内置的带「内置」标签）、说明、数据范围、IP 白名单、员工数。右上角「新建角色」。
- 详情 / 编辑：
  - 内置角色：只读，顶部提示「复制为新角色」；只显示权限表。
  - 自建角色：名字、说明；权限表（菜单 × 查看 / 编辑 / 审核 / 导出，没有的格子是「—」，只归超级管理员的三格写明）；数据范围（城市、渠道：不限 / 只看选中的）；IP 白名单；给审核同事的说明；「提交修改（需审核）」「删除角色」。
  - 勾编辑 / 审核自动带上查看；去掉查看同一行的其他格一起去掉。
- 「待审核」里多两类：修改角色（列出名字、权限、数据范围、IP 白名单改前改后）、重置两步验证。

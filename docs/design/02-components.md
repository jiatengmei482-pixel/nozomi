# 组件规范

所有数值都引用 [`tokens.css`](./tokens.css) 的令牌。每个组件写四件事：尺寸、各状态、手机下怎么办、键盘与无障碍。

通用约定：

- 聚焦环写法见 `01-tokens.md` 第 5 节，所有可聚焦元素都要有。
- 悬停样式只在 `@media (hover: hover)` 下生效，避免触屏点完后「粘住」。
- 颜色过渡 `var(--duration-fast)`。
- 可点击区域最小 24×24px；触屏下控件高度由令牌自动变为 44px。
- 优先用原生元素（`<button>`、`<a>`、`<input>`、`<select>`、`<dialog>`、`<table>`），它们自带键盘行为和语义。只有原生元素做不到时才自己拼，并补齐 ARIA。

## 1. 按钮

| 类型 | 用在哪 | 默认 | 悬停 | 按下 |
| --- | --- | --- | --- | --- |
| 主按钮 | 一个区域里最该点的那一个（保存、登录、确认派车）。**每个区域最多一个** | 底 `primary`，字 `on-primary` | 底 `primary-hover` | 底 `primary-active` |
| 次要按钮 | 其他操作（取消、导出、筛选） | 底 `bg-surface`，边框 `border-strong`，字 `text-primary` | 底 `bg-hover` | 底 `bg-subtle` |
| 文字按钮 | 表格行内操作、不重要的操作 | 无底无边，字 `text-link` | 底 `primary-subtle` | 底 `bg-selected` |
| 危险按钮 | 不可恢复的操作的最终确认（停用、删除、声明无法履约） | 底 `danger-solid`，字 `on-danger` | 底 `danger-solid-hover` | 底 `danger-solid-active` |

- 尺寸：高 `control-height-sm / md / lg`；左右内边距 `space-3`（sm 为 `space-2`，lg 为 `space-4`）；字号 `font-size-md`（lg 为 `font-size-lg`）；字重 `font-weight-medium`；圆角 `radius-md`；最小宽度 64px。文字不换行。
- 图标 + 文字：图标 16px，间距 `space-1`。只有图标的按钮宽高相等，必须有 `aria-label`，并在悬停和聚焦时显示同样文字的气泡提示。
- **禁用**：底 `bg-disabled`，字 `text-disabled`，无边框，`cursor: not-allowed`。用原生 `disabled`。按钮因为缺少条件而禁用时，旁边要有文字说明原因（如「请先选择司机」），不能只是灰掉。
- **加载中**（已点击，等待结果）：保持原来的颜色和宽度，文字前加 16px 转圈，文字改成进行时（「保存中…」「正在登录…」）；设 `aria-busy="true"`，不响应再次点击。不要用 `disabled`，否则焦点会丢。
- 排列：一组按钮间距 `space-2`。桌面端主按钮在最右；对话框和表单底部同此。手机下（< 480px）表单和对话框底部的按钮各占一行、撑满宽度，主按钮在最上。
- 危险操作的入口（列表里的「停用」）用次要按钮或文字按钮加 `danger-text` 文字色，只有二次确认对话框里的最终确认才用危险按钮。
- 键盘：Tab 聚焦，Enter 和空格触发。跳转页面用 `<a>`，执行操作用 `<button>`，不要混用；`<button>` 一律写明 `type`。

## 2. 输入框

- 尺寸：高 `control-height-md`（登录页、官网、司机 H5 用 `lg`）；左右内边距 `space-3`；字号 `control-font-size`；圆角 `radius-md`；宽度撑满所在栅格列。多行文本框最少 3 行，可纵向拉伸，不可横向拉伸。
- 默认：底 `bg-surface`，边框 1px `border-strong`，字 `text-primary`，占位文字 `text-tertiary`。
- 悬停：边框 `text-secondary`。
- 聚焦：聚焦环 `border-focus`，`outline-offset: -1px`。
- 出错：边框 2px `danger-solid`（内边距相应减 1px，避免抖动）；下方显示出错文字（见第 4 节）。`aria-invalid="true"`。
- 禁用：底 `bg-disabled`，字 `text-disabled`，边框 `border-default`。
- 只读：底 `bg-subtle`，字 `text-primary`，边框 `border-default`，可以选中复制，可以聚焦。
- 前后缀（币种代码、单位「分钟」「公里」、显示密码按钮）放在输入框内部两端，字色 `text-secondary`，不能被输入内容盖住。
- 占位文字只用来举格式的例子，不能代替标签。
- 按内容设置 `type`、`inputmode`、`autocomplete`：邮箱 `type="email"`，电话 `type="tel"`，金额和数量 `inputmode="decimal"` 或 `"numeric"`。**金额和数量不用 `type="number"`**（滚轮会误改数值，且不同浏览器对小数处理不一致）。
- 密码框右侧有「显示密码 / 隐藏密码」图标按钮，`aria-pressed` 表示当前状态。

## 3. 选择器

| 场景 | 用什么 |
| --- | --- |
| 选项 ≤ 10 个、不需要搜索 | 原生 `<select>`，外观与输入框一致，右侧 16px 下箭头 |
| 选项多、需要搜索或多选（城市、机场、司机、车辆、车型组） | 组合框：输入框 + 下拉面板 |
| 2–4 个互斥选项且需要一眼看到全部（品类、计费方式） | 单选按钮组 |
| 开 / 关，立即生效 | 开关 |
| 开 / 关，随表单一起保存 | 复选框 |

**组合框**

- 面板：底 `bg-surface`，边框 `border-default`，圆角 `radius-lg`，阴影 `shadow-md`，层级 `z-dropdown`；最大高度 320px，内部纵向滚动；宽度不小于输入框，不超出视口（距屏幕边缘至少 `space-2`）。
- 选项：高 `control-height-md`；悬停或键盘高亮 `bg-hover`；已选中 `bg-selected` 并在右侧显示对勾（不只靠底色）。
- 多选：已选项以可删除的小标签显示在输入框内，超过一行时换行增高，不横向溢出。
- 状态：加载中显示「加载中…」；无匹配显示「没有匹配的选项」；加载失败显示「加载失败」和「重试」。
- 手机（< 480px）：面板改为从底部升起的面板，宽度撑满，最高占屏幕 70%。
- 键盘：↓ 打开；↑↓ 移动高亮；Enter 选中；Esc 关闭并把焦点留在输入框；输入文字即筛选。
- 无障碍：输入框 `role="combobox"`、`aria-expanded`、`aria-controls`、`aria-activedescendant`；面板 `role="listbox"`；选项 `role="option"` + `aria-selected`。

**复选框、单选、开关**

- 方框和圆点 16×16px，边框 `border-strong`；选中后底 `primary`，对勾 `on-primary`。开关 36×20px，关闭时底 `border-strong`，打开时底 `primary`，滑块 `bg-surface`。
- 文字标签在右侧，间距 `space-2`，点文字也能切换（用 `<label>` 包住）。整行可点击区域高度不小于 `control-height-md`。
- 开关旁边必须有文字写出当前状态（「已启用」/「已停用」），不能只靠颜色和滑块位置。
- 用原生 `<input type="checkbox">` / `<input type="radio">`；开关加 `role="switch"`。单选组用 `<fieldset>` + `<legend>`，↑↓←→ 在组内切换。

## 4. 表单布局与校验提示

**布局**

- 标签在输入框**上方**，左对齐，字号 `font-size-sm`，字重 `font-weight-medium`，字色 `text-secondary`，与输入框间距 `space-1`。不用左右排列的标签（手机放不下，中日英长度差别大）。
- 必填项在标签后加红色星号（`danger-text`，`aria-hidden="true"`），同时输入框设 `required`。一个表单里大部分都必填时，反过来只在选填项的标签后写「（选填）」。
- 帮助说明在输入框下方，`font-size-sm`，`text-tertiary`，间距 `space-1`。出错时，出错文字显示在帮助说明的位置上方，帮助说明保留。
- 字段之间纵向间距 `space-4`。分组之间 `space-8`，每组有一个标题（`font-size-lg`，`font-weight-bold`）。
- 栏数：< 768px 单栏；≥ 768px 最多两栏，栏间距 `space-4`。长文本、地址、多选占整行。表单最大宽度 `layout-form-max-width`。
- 底部操作区：与最后一个字段间距 `space-6`。长表单的操作区吸在视口底部（底 `bg-surface`，上边线 `border-default`，层级 `z-sticky`）。
- 离开未保存的表单时弹确认：「有未保存的修改，确定离开吗？」

**校验**

- 时机：字段第一次失去焦点时校验；出过错的字段在输入过程中实时重新校验；点提交时全部校验。不在用户刚开始输入时就报错。
- 字段出错：输入框换成出错样式；下方显示出错文字，`font-size-sm`，`danger-text`，前面带 14px 的警示图标（图标 + 文字，不只靠红色）。出错文字的元素用 `aria-describedby` 关联到输入框。
- 提交时有错：焦点移到第一个出错的字段，并滚动到可见位置。字段超过一屏的表单，另在表单顶部放一条危险提示条：「有 N 处需要修改」，列出字段名，点字段名跳到对应字段。
- 后端返回的字段错误显示在对应字段下；不属于某个字段的错误显示在表单顶部的提示条里。
- 出错文字写清「错在哪 + 怎么改」：写「请输入邮箱」「结束日期不能早于开始日期」，不写「输入无效」「参数错误」。
- 提交中：提交按钮进入加载态，其他字段设为只读，直到有结果。提交失败后保留用户已填的所有内容。

## 5. 表格

- 容器：底 `bg-surface`，边框 `border-default`，圆角 `radius-lg`，`overflow-x: auto`。**表格只在自己的容器里横向滚动，页面本身不滚动。** 容器加 `tabindex="0"`、`role="region"`、`aria-label`（表格名称），让键盘用户能用方向键横向滚动。
- 表头：底 `bg-subtle`，字号 `font-size-sm`，字重 `font-weight-medium`，字色 `text-secondary`，高 `table-row-height`，不换行。纵向滚动时吸顶（`z-sticky`）。
- 行：最小高度 `table-row-height`；单元格内边距上下 `space-2`、左右 `space-3`；行间用 `border-default` 分隔，不用斑马纹；悬停 `bg-hover`；选中 `bg-selected`。
- 对齐：文字左对齐；金额和数量右对齐并用等宽数字；状态徽标左对齐；操作列在最右。表头与内容对齐方式一致。
- 列宽：编号、日期、金额、状态、操作不换行；名称、地址等长文字最多两行，超出用省略号，完整内容放在 `title` 和详情页里。
- 行内操作：最多 2 个文字按钮，其余收进「更多」菜单。
- 排序：可排序的表头是一个 `<button>`，右侧有箭头标出方向；所在 `<th>` 设 `aria-sort`。
- 多选：首列复选框，表头的复选框表示全选当前页（部分选中时为半选状态）。选中后在表格上方显示「已选 N 项」和批量操作。
- 需要置顶提醒的行（如超过派车截止时间未派车）：行首加 3px `danger-solid` 竖条，并且状态列的徽标文字写明原因（「超时未派车」）。不把整行染红。
- 语义：用真正的 `<table>`、`<thead>`、`<th scope="col">`。整行可点进详情时，第一列的编号是一个 `<a>`，不要只给 `<tr>` 绑点击。

**手机宽度（< 768px）下的两种呈现，按表格用途选一种：**

| 方式 | 用于 | 做法 |
| --- | --- | --- |
| A. 容器内横向滚动（默认） | 列多、主要在桌面用的表（价格规则、对账明细、审计日志、调用日志） | 表格保持原样，容器横向滚动；第一列（编号或名称）固定在左侧（`position: sticky`，底 `bg-surface`，右侧加 `border-default`）；容器右边缘在可继续滚动时显示 16px 的渐隐，提示还有内容 |
| B. 卡片列表 | 会在手机上处理的表（订单列表、派车、工单、司机、车辆） | 每行变成一张卡片：第一行是编号 + 状态徽标（两端对齐），接着是 2–4 个关键字段（「标签：值」逐行排），最下面是操作按钮。卡片间距 `space-2`，内边距 `space-4`。其余字段进详情页看 |

每个页面的说明里要写明用 A 还是 B；用 B 时列出卡片上保留哪几个字段。

**筛选条**：在表格上方，控件用 `sm` 尺寸，间距 `space-2`，放不下自动换行。< 768px 时只保留搜索框和一个「筛选」按钮，其余条件收进从底部升起的面板；按钮上显示已生效的条件数（「筛选 · 2」）。已生效的条件在表格上方以可删除的小标签列出，并提供「清空筛选」。

筛选条的细则：

- 排列顺序固定：搜索框在最左（宽 `min(280px, 100%)`），然后是各个条件，最右是「清空筛选」（文字按钮，只在有条件生效时出现）。
- 每个条件控件都有可见的标签：下拉选择把标签写在控件内左侧（「状态：全部」），不能只靠占位文字。
- 搜索框：左侧 16px 放大镜图标，`type="search"`，`aria-label` 写明搜什么（「按编码或名称搜索」）；有内容时右侧出现清除按钮（`aria-label="清除搜索"`）。停止输入 300ms 后自动查询，按 Enter 立即查询；输入法正在组字时（拼音、假名还没上屏）不查询。
- 其他条件一改就查询，不设「查询」按钮。
- 每个条件对应一个网址参数，参数名用小写英文；取默认值的条件不写进网址。改条件用 `replace` 而不是 `push`，不让浏览器的「后退」被筛选记录塞满。
- 改任何条件都回到第一页。
- < 768px 的「筛选」面板：标题「筛选」，条件纵向排列、控件用 `md` 尺寸，底部两个按钮「清空」（次要）和「查看结果」（主按钮）；点「查看结果」才生效并关闭面板。面板是模态的，规则同对话框。

## 6. 分页

- 位置：表格容器下方，间距 `space-3`。左侧「共 N 条」，右侧是每页条数选择（20 / 50 / 100，默认 20）和翻页按钮。
- 翻页：「上一页」「下一页」+ 页码，都是 `sm` 尺寸的次要按钮。页码最多显示 7 个，多出的用「…」代替。当前页底 `primary-subtle`、字 `text-link`、`aria-current="page"`。
- 第一页时「上一页」禁用，最后一页时「下一页」禁用。
- 手机（< 480px）：只显示「上一页」「第 X / Y 页」「下一页」；「共 N 条」移到上一行。
- 翻页后表格滚回顶部，焦点移到表格容器。筛选条件、页码、每页条数写进网址参数，刷新和分享链接后保持不变。
- 外层用 `<nav aria-label="分页">`。
- 后端用游标分页的列表（没有总页数）：只显示「上一页」「下一页」，不显示页码和总条数。细则：
  - 后端只给「下一页」的游标。前端把走过的每一页的游标按顺序记在内存里（一个栈），「上一页」就是取栈里的上一个；第一页时「上一页」禁用，后端返回的下一页游标为空时「下一页」禁用。
  - 左侧：后端同时返回了符合条件的总数时照常显示「共 N 条」；没有总数时改为显示「本页 N 条」。每页条数选择保留。有总数也不显示页码（游标分页不能跳页）。
  - 游标不写进网址：刷新页面、分享链接都回到第一页（筛选条件和每页条数仍然保留）。从列表进编辑页再回来时，列表要恢复到离开时的那一页和滚动位置（把游标栈放在这条浏览记录的状态里），不要让人每次都从第一页重新翻。
  - 改筛选条件、改每页条数：清空游标栈，回到第一页。
  - 当前页的内容因为操作而变少（例如在「待处理」筛选下处理掉了一条）：不自动补位、不跳页；这一页全部处理完时显示「这一页已经处理完了」和主按钮「看下一批」（没有下一页时显示该列表的「筛选后没有结果」空状态）。

## 7. 标签与状态徽标

**状态徽标**

- 尺寸：高 22px；内边距 `space-0-5` / `space-2`；字号 `font-size-xs`；字重 `font-weight-medium`；圆角 `radius-sm`；不换行。
- 样式：底 `{状态}-bg`，字 `{状态}-text`，边框 1px `{状态}-border`。文字前有一个 6px 圆点，颜色同文字。
- **文字必须写出状态名**。同一个页面里两种状态即使颜色相同，文字也必须不同。
- 颜色按含义选，同一个状态在所有页面用同一个颜色：

| 颜色 | 含义 | 需求文档里出现的状态（举例） |
| --- | --- | --- |
| `neutral` | 还没开始、已结束且无需关注 | 草稿、未上架、已下架、已停用、已取消 |
| `info` | 正在进行、等待对方 | 待派车、已派车、已出发、已到达、已接到客人、审核中 |
| `success` | 正常结束、可用 | 已上架、已完成、已通过、在职、可用 |
| `warning` | 有时限、快到期、需要留意 | 即将到期、派车截止前提醒、维修 |
| `danger` | 已超时、失败、被拒绝 | 超时未派车、已到期、已拒绝、投递失败 |

每个业务对象的「状态 → 颜色 → 显示文字」对照表写在一个地方（前端的一个常量文件），页面不各自决定。新增状态时由美工确定颜色。

**标签**（表示属性，不表示状态：品类、车型组、语言、「新车」「金牌司机」）

- 尺寸同状态徽标；底 `bg-subtle`，字 `text-secondary`，无边框，无圆点。
- 可删除的标签（多选的已选项、已生效的筛选条件）右侧有 × 按钮，`aria-label="移除 {名称}"`。

## 8. 提示条与 Toast

**提示条**（留在页面里，直到情况改变或用户关闭）

- 用于：页面或表单级别的错误、需要用户知道的持续状态（如「资质审核通过前不能上架」）。
- 样式：底 `{状态}-bg`，边框 `{状态}-border`，圆角 `radius-md`，内边距 `space-3`；左侧 16px 图标（色 `{状态}-text`），标题 `font-weight-medium` + `{状态}-text`，正文 `text-primary`，字号 `font-size-md`。可带一个文字按钮（「重试」「去处理」）。
- 四种：`info`、`success`、`warning`、`danger`，各自用固定的图标（信息、对勾、三角警示、圆形叹号）。图标形状不同，不只靠颜色。
- 位置：页面级放在页面标题下方；表单级放在表单顶部。
- 无障碍：出错和警告用 `role="alert"`（出现时立即读出）；信息和成功用 `role="status"`。

**Toast**（短暂出现，自动消失）

- 只用于确认「刚才的操作成功了」（「已保存」「已复制」「已派车」）。**出错不用 Toast**：错误用提示条或字段提示，留在原地直到解决。
- 样式：底 `bg-inverse`，字 `text-inverse`，圆角 `radius-md`，阴影 `shadow-md`，内边距 `space-3` / `space-4`，层级 `z-toast`；最大宽度 `min(360px, 100% - 32px)`。
- 位置：桌面端顶部居中，距顶 `space-4`；手机端底部居中，距底 `space-4` 再加上 `env(safe-area-inset-bottom)`。
- 停留 4 秒；鼠标悬停或键盘聚焦时暂停计时。带「撤销」按钮的停留 8 秒。同时最多显示 3 条，新的在下方。
- 无障碍：放在一个始终存在的 `role="status"` + `aria-live="polite"` 区域里；不抢焦点。
- 结构：左侧 16px 对勾图标（色 `text-inverse`）+ 一句话（最多两行，`overflow-wrap: anywhere`）+ 可选的一个文字按钮（「撤销」，字 `text-inverse` 加下划线）+ 右侧关闭按钮（`aria-label="关闭提示"`，图标色 `text-inverse`）。关闭按钮和「撤销」的聚焦环用 `text-inverse` 色（在反色底上 `border-focus` 不够清楚）。
- 文案：写「已 + 动作 + 对象」，对象名称用「」括起来：「已启用「羽田机场」」「已新增城市「东京」」「已保存」。不加感叹号，不写「成功」二字以外的客套话。名称超过 20 个字时截断加省略号。
- 整个后台只有一个 Toast 容器，挂在后台框架最外层（和登录等不带框架的页面的最外层），不随页面切换而销毁：**跳转前发出的 Toast 在跳转后的页面上照常显示**（「保存后回到列表」就是这种情况）。
- 出现和消失：`opacity` + 8px 位移，`duration-base`；设置了「减少动态效果」时直接出现和消失。
- 手机上如果页面底部有吸底的操作区，Toast 显示在操作区上方，不盖住按钮。
- 同一句话在还显示着的时候再次触发：不叠加新的一条，把原来那条的计时重置。
- 亮色下是深底白字，暗色下是浅底深字（`bg-inverse` / `text-inverse` 已按主题切换），两套都要看一遍。

**成功之后用 Toast 还是成功提示条**

| 情况 | 用什么 |
| --- | --- |
| 操作成功，用户不需要再知道别的（已保存、已启用、已停用、已新增、已复制） | Toast |
| 操作成功，但带来了一个用户需要读到、可能影响下一步的后果（「这个账号在其他设备上的登录已全部退出」「密码已设置，请登录」） | 成功提示条，留在页面里，直到用户离开或开始下一次操作 |
| 成功后跳到了别的页面 | Toast（提示条不跟着跳转走，唯一的例外是登录页已有的三条进入提示，见 `pages/login.md`） |

## 9. 对话框

- 用于：二次确认、不离开当前页的简短表单（一屏以内）。更长的内容用单独的页面。
- 尺寸：宽 `min(480px, 100% - 32px)`（确认）或 `min(640px, 100% - 32px)`（表单）；最大高度 `100dvh - 64px`，超出时只有正文区域纵向滚动，标题和底部按钮固定。
- 样式：底 `bg-surface`，边框 `border-default`，圆角 `radius-xl`，阴影 `shadow-lg`，内边距 `space-5`，层级 `z-dialog`；遮罩 `bg-overlay`，层级 `z-overlay`。
- 结构：标题（`font-size-xl`，`font-weight-bold`）+ 右上角关闭按钮（`aria-label="关闭"`）；正文；底部按钮右对齐，主按钮在最右。
- 手机（< 480px）：贴底显示，宽度撑满，只有上方两个角有圆角；底部按钮各占一行，底部留出 `env(safe-area-inset-bottom)`。
- **危险操作的确认**：标题直接写要做的事（「停用这个司机？」）；正文写清后果（会影响什么、能不能恢复、要扣多少钱）；确认按钮用危险按钮，文字写动作本身（「停用」），不写「确定」；取消按钮写「取消」。默认焦点落在「取消」上。
- 打开时：焦点移到对话框内第一个可操作的元素（危险确认时是「取消」）；Tab 只在对话框内循环；背景内容不可操作、不可滚动。
- 关闭：Esc、关闭按钮、取消按钮。点遮罩可以关闭确认类对话框；**有表单的对话框点遮罩不关闭**，避免误丢内容。关闭后焦点回到打开它的那个按钮。
- 实现：用原生 `<dialog>` 的 `showModal()`，或 `role="dialog"` + `aria-modal="true"`；`aria-labelledby` 指向标题。
- 不在对话框里再开对话框。
- **确认后在等结果**：确认按钮进入加载态（「停用中…」），「取消」和关闭按钮不可用，Esc 和点遮罩不关闭。成功后关闭对话框并发 Toast。
- **确认后被业务规则拒绝**（例如还有下级在用，不能停用）：对话框不关闭，标题不变；正文换成一条危险提示条写明原因和下一步（`role="alert"`）；确认按钮从对话框里去掉（再点一次结果也一样），「取消」改成「知道了」并成为默认焦点；提示条里可以带一个去处理的链接。
- **确认后网络不通或服务器出错**：对话框不关闭，正文上方加危险提示条（文案同第 13 节），确认按钮恢复可点，可以直接再试一次。

## 10. 导航

后台框架的尺寸见 `03-layout.md`。

**侧边栏**

- 宽 `layout-sidebar-width`；底 `bg-surface`，右边线 `border-default`；内部可纵向滚动。
- 顶部是品牌名 NOZOMI 和当前后台的名称（「运营后台」或「供应商后台」）。
- 菜单项：高 36px（触屏 44px）；左右内边距 `space-3`；16px 图标 + 文字，间距 `space-2`；字号 `font-size-md`；字色 `text-secondary`；圆角 `radius-md`。
  - 悬停：底 `bg-hover`，字 `text-primary`。
  - 当前页：底 `primary-subtle`，字 `text-link`，字重 `font-weight-medium`，左侧 3px `primary` 竖条；`aria-current="page"`。
- 二级菜单：一级项可展开，子项缩进 `space-6`；一级项是 `<button aria-expanded>`。当前页所在的分组默认展开。最多两级。
  - 分组项本身不是页面，点它只展开或收起，右侧有一个 16px 箭头（收起时朝右、展开时朝下）。子项没有图标，只有文字。
  - 当前页在某个分组里而分组被用户收起时，分组项自己显示「当前页」的文字色和字重（没有底色和竖条），让人知道自己在这个分组里。
  - 展开 / 收起的状态存在浏览器本地；当前页所在的分组在进入页面时总是展开的。
  - 一个分组里当前角色能看到的子项一个都没有时，整个分组不显示。
  - 编辑页、新增页没有自己的菜单项：它们所属的列表页的菜单项显示为当前页。
  - 侧边栏收起成只剩图标时，分组项的图标悬停或聚焦后弹出子项菜单（下拉面板样式）。
- 运营后台的菜单分组与顺序见 [`pages/platform-home.md`](./pages/platform-home.md) 第 2 节。
- 只显示当前角色有权限的菜单；没有权限的不显示（不是置灰）。
- 待办数量：菜单项右侧的数字徽标（底 `danger-bg`，字 `danger-text`，`radius-full`），超过 99 显示「99+」，并在 `aria-label` 里读出（「工单，3 条待处理」）。
- ≥ 1024px：常驻显示。可以收起成 `layout-sidebar-width-collapsed` 宽，只剩图标，悬停和聚焦时用气泡显示名称；收起状态存在浏览器本地。
- < 1024px：默认不显示。点顶栏左侧的菜单按钮后从左侧滑入，宽 `min(280px, 100% - 56px)`，层级 `z-sidebar`，阴影 `shadow-lg`，后面是遮罩。此时它是一个模态面板：焦点限制在内部；Esc、点遮罩、点任一菜单项后关闭；关闭后焦点回到菜单按钮。
- 外层 `<nav aria-label="主菜单">`。

**顶栏**

- 高 `layout-topbar-height`；底 `bg-surface`，下边线 `border-default`；吸顶，层级 `z-topbar`。
- 左侧：菜单按钮（仅 < 1024px 显示，`aria-label="打开菜单"`，`aria-expanded`）、面包屑。
- 右侧：主题切换（跟随系统 / 亮色 / 暗色）、当前账号（姓名 + 角色，点开是下拉菜单：个人设置、退出登录）。
- < 768px：面包屑只显示当前页名称；账号只显示头像或姓名首字，角色名收进下拉菜单。
- 平台员工「以某租户身份查看」供应商后台时，顶栏下方加一条不能关闭的警告提示条，写明正在查看的租户名称和「只读」，并提供「退出查看」按钮。

**跳到正文**：页面第一个可聚焦元素是「跳到正文」链接，平时不可见，聚焦时显示在左上角，跳到 `<main>`。

**面包屑**：`font-size-sm`，层级之间用「/」分隔；前面几级是链接（`text-link`），最后一级是当前页（`text-primary`，`aria-current="page"`）。外层 `<nav aria-label="当前位置">`。

**页签**（一个页面里的平级分区，如地点列表的「机场 / 车站 / 地标」。**有先后顺序、要显示每一步做完没有的，用步骤导航（第 24 节），不用页签**——商品的「基础信息 / 服务规则 / 价格规则 / 库存 / 商品详情」就是步骤导航）：高 40px；当前项字 `text-link`、下方 2px `primary` 横线；其余字 `text-secondary`。放不下时页签条自己横向滚动，不换行，也不撑宽页面。`role="tablist"` / `role="tab"` / `role="tabpanel"`，←→ 切换。

## 11. 空状态

- 位置：在本该出现内容的区域里居中（表格就在表格容器内，表头保留），上下留白 `space-10`。
- 内容：一句标题（`font-size-lg`，`font-weight-medium`，`text-primary`）+ 一句说明（`font-size-md`，`text-secondary`，最多两行）+ 最多一个按钮。不用插图。
- 区分三种情况，文案不能混用：

| 情况 | 标题怎么写 | 说明怎么写 | 按钮 |
| --- | --- | --- | --- |
| 还没有任何数据 | 「还没有{对象}」 | 一句话说明这个东西是干什么的、下一步做什么 | 有新建权限时放主按钮「新建{对象}」；没有权限时不放 |
| 有数据，但筛选或搜索后没有结果 | 「没有符合条件的{对象}」 | 「换个条件试试，或清空筛选。」 | 次要按钮「清空筛选」 |
| 没有权限看 | 「你没有权限查看这里」 | 「需要的话，请联系管理员开通。」 | 无 |

- 不显示假数据、示例行来填充空白。

## 12. 加载状态

| 场景 | 做法 |
| --- | --- |
| 页面或区域首次加载 | 骨架屏：按最终布局画出灰块（底 `bg-subtle`，圆角 `radius-sm`）。表格画表头 + 5 行灰条。加载完成后布局不跳动 |
| 已有内容，正在刷新（翻页、改筛选） | 保留旧内容并降到 60% 不透明度，区域顶部显示 2px 的 `primary` 进度条；不清空成骨架屏 |
| 按钮触发的提交 | 按钮加载态（见第 1 节） |
| 下拉面板、小区域 | 16px 转圈 + 「加载中…」 |

- 请求在 300ms 内返回时不显示任何加载样式，避免闪一下。
- 超过 10 秒仍未返回：在加载区域里加一行「加载时间比平时长，请稍等，或刷新页面重试。」
- 无障碍：加载中的区域设 `aria-busy="true"`；骨架屏 `aria-hidden="true"`，另放一个只给读屏的「加载中」（`role="status"`）。
- 转圈动画在用户设置了「减少动态效果」时不转，改为静止图标 + 文字。

## 13. 错误状态

| 情况 | 显示在哪 | 文案 | 操作 |
| --- | --- | --- | --- |
| 某个区域加载失败（列表、卡片） | 该区域内，版式同空状态，图标用圆形叹号（`danger-text`） | 标题「加载失败」；说明「请检查网络后重试。」 | 次要按钮「重试」 |
| 提交失败（网络问题、服务器错误） | 表单顶部的危险提示条 | 「保存失败，请稍后重试。你填写的内容还在。」 | 用户再点一次提交 |
| 提交被业务规则拒绝 | 对应字段下方，或表单顶部的危险提示条 | 用后端返回的中文说明，写清原因和怎么办 | 视情况 |
| 登录已过期 | 跳到登录页，登录页显示信息提示条 | 「登录已过期，请重新登录。」 | 登录后回到原来的页面 |
| 没有权限（403） | 内容区 | 同空状态的「没有权限」 | 无 |
| 页面不存在（404） | 内容区（保留侧边栏和顶栏） | 标题「找不到这个页面」；说明「它可能已被删除，或链接有误。」 | 主按钮「回到首页」 |
| 整个页面出错（前端异常、服务不可用） | 整页，居中 | 标题「页面出了点问题」；说明「请刷新重试。如果一直这样，请把下面的编号发给管理员。」 | 主按钮「刷新页面」 |

- 后端返回了请求编号时，在错误说明下方用等宽字体显示「编号：{请求编号}」，并提供「复制」按钮，方便用户报给管理员。
- 不向用户显示状态码、堆栈、英文原始报错、内部字段名。
- 一处出错不影响页面其他部分：侧边栏、顶栏和其他卡片照常可用。
- 出错后保留用户已经填写的内容和筛选条件。

## 14. 气泡提示

- 只放补充信息（图标按钮的名称、被截断文字的全文、时间的另一种时区表示）。必须读到的信息不放在气泡里。
- 样式：底 `bg-inverse`，字 `text-inverse`，`font-size-sm`，圆角 `radius-sm`，内边距 `space-1` / `space-2`，最大宽度 240px，层级 `z-tooltip`。
- 悬停 400ms 后出现；键盘聚焦时立即出现；Esc 关闭；鼠标移到气泡上时不消失。
- 触屏没有悬停：需要在手机上看到的内容不能只放在气泡里。
- `role="tooltip"`，触发元素用 `aria-describedby` 关联。

## 15. 图标

- 一套线性图标，以内联 SVG 的形式放在代码仓库里，`stroke="currentColor"`，颜色跟随文字。不引用外部图片或图标字体。具体选用哪一套开源图标由前端决定（要求：许可证允许商用、线宽一致、可以只打包用到的图标）。
- 尺寸：16px（正文和按钮里）、20px（顶栏、司机 H5）。
- 装饰性的图标加 `aria-hidden="true"`；单独表达含义的图标必须有文字替代（`aria-label` 或旁边的隐藏文字）。

## 16. 多语言输入组

同一项内容要填几种语言时用（主数据的名称、说明）。语言固定四种，顺序固定：**中文（zh）、日语（ja）、英语（en）、韩语（ko）**。

```
名称 *
┌──────┬───────────────────────────────┐
│ 中文  │ [                           ] │
│ 日语  │ [                           ] │
│ 英语  │ [                           ] │
│ 韩语  │ [                           ] │
└──────┴───────────────────────────────┘
至少填一种语言。
```

- 外层是 `<fieldset>`，`<legend>` 就是字段标签（样式同普通字段标签，必填时带星号）。四行之间间距 `space-2`，整组与其他字段的间距仍是 `space-4`。
- 每行：左侧语言名（`font-size-sm`，`text-secondary`，固定宽 `space-12`，不换行）+ 右侧输入框（`minmax(0, 1fr)`）。语言名是这个输入框的 `<label>`；读屏读到的是「名称 中文」（给输入框加 `aria-label="{字段名} {语言名}"`，或用 `aria-labelledby` 把 legend 和语言名连起来）。
- 每个输入框带 `lang` 属性：`zh-Hans`、`ja`、`en`、`ko`。日语那一行因此用日文字形显示（`01-tokens.md` 第 2 节）。
- 多行的变体（说明）：每行换成多行文本框（3 行起，可纵向拉伸）；< 480px 时语言名移到文本框上方。
- **每种语言是独立的输入框，全部同时可见，不做成页签**：做成页签的话，没切过去的语言容易被忘掉，也看不出哪种还没填。
- 校验：
  - 「至少填一种」的错误属于整组：出错文字显示在整组下方（帮助说明的上方），整个 `<fieldset>` 用 `aria-describedby` 关联它；四个输入框都换成出错样式；焦点移到第一行。任意一行填了内容后错误立即消失。
  - 某一种语言超长等错误只属于那一行：出错文字写明语言（「日语名称最多 200 个字」），只有那一行换成出错样式。
  - 只有空格、看不见的字符的，等于没填（判断用 `@nozomi/domain` 的 `hasVisibleText`）。提交前去掉每种语言首尾的空格。
- 提交的数据：只带填了内容的语言。**后端对这类字段是整体替换**，所以编辑时必须先把已有的全部语言填进表单，提交时把四行当前的内容一起带上；只提交改过的那一种会把其他语言清掉。用户把某一行清空再保存，就是删掉那种语言。
- 在列表和只读的地方显示多语言名称（「显示名」）：按 中文 → 英语 → 日语 → 韩语 的顺序取第一个有内容的，所在元素带上对应的 `lang`。全站一个函数，页面不各自取。

## 17. 可增减的行

一个字段由若干条同样结构的小记录组成时用（车型组的「人数 / 行李数」组合、代表车型）。

- 外层 `<fieldset>` + `<legend>`（字段标签）。每条记录一行：一到三个输入框 + 行尾的删除按钮（只有图标的文字按钮，×，`aria-label="删除第 N 个{对象}"`）。行间距 `space-2`。
- 每个输入框有自己的可见标签：第一行上方显示列标题（`font-size-sm`，`text-secondary`），其余各行的输入框用 `aria-label` 带上行号（「第 2 个组合的人数」）。< 480px 时不显示列标题，改为每个输入框内用前缀文字标明（「人数」「行李」）。
- 最后一行下方是「添加{对象}」（次要按钮，`sm` 尺寸，带加号图标）。达到数量上限时按钮禁用，旁边写「最多 N 个」。
- 至少要有一条的字段：只剩一条时，那一条的删除按钮禁用，`title` 和旁边的帮助说明写「至少保留一个」。
- 点「添加」后焦点进入新行的第一个输入框；删除一行后焦点移到下一行的第一个输入框，没有下一行就移到「添加」按钮。
- 校验：某一行某一格的错误显示在那一行下方，只标红出错的那一格；属于整组的错误（「至少要有一个」「和前面的重复」）显示在整组下方。
- 行不提供拖动排序。提交时保持用户看到的顺序。
- 窄屏：一行里的输入框等分宽度（`minmax(0, 1fr)`），删除按钮固定宽度；整行不换行也不溢出。

## 18. 入口卡片

首页上「进入某个模块 + 看一眼数量」用。

```
┌──────────────────────────┐
│ 地点                    › │   标题行：模块名 + 箭头
│ 5 启用   ·   97 已停用     │   数量行
│ ⚠ 97 个机场待指定城市  ›   │   提醒行（有才显示）
└──────────────────────────┘
```

- 容器：卡片样式（`03-layout.md` 第 2 节），内边距 `space-4`，三行之间间距 `space-2`。栅格用 `repeat(auto-fill, minmax(min(240px, 100%), 1fr))`，间距 `space-4`。同一行的卡片等高。
- **标题行**：模块名是一个 `<a>`（`font-size-lg`，`font-weight-bold`，`text-primary`），右侧 16px 向右箭头（`text-tertiary`，`aria-hidden`）。链接用 `::after { position: absolute; inset: 0 }` 把可点区域铺满整张卡片（卡片 `position: relative`）。悬停：卡片边框换成 `border-strong`，模块名换成 `text-link`；聚焦环画在整张卡片上（`:focus-within` 时给卡片加聚焦环，链接自身的去掉）。
- **数量行**：一到三组「数字 + 说明」，组与组之间用「·」分隔，放不下自动换行。数字 `font-size-2xl`、`font-weight-bold`、`text-primary`、等宽数字、带千分位；说明 `font-size-sm`、`text-secondary`，在数字右侧，间距 `space-1`。**数字的含义全靠说明文字表达，不用颜色区分「启用」和「停用」。** 数量行用 `<dl>`（说明是 `<dt>`，数字是 `<dd>`，视觉上数字在前）。
- **提醒行**（有需要处理的事才显示，一张卡片最多两条）：底 `warning-bg`，边框 `warning-border`，圆角 `radius-md`，内边距 `space-1` / `space-2`；16px 三角警示图标（`warning-text`）+ 文字（`font-size-sm`，`text-primary`）+ 右侧向右箭头（`warning-text`；状态底色上不能用 `text-tertiary`）。它自己是一个 `<a>`，去到已经筛好的列表；要加 `position: relative`，这样它盖在标题链接铺开的那一层上面、能单独点到（不写 `z-index` 数字）。
- **还没有对应页面的模块**：只显示模块名和数量，模块名是普通文字不是链接，没有箭头，没有悬停效果。不写「即将上线」之类的话。
- 状态：
  - 数量加载中：标题行照常显示并且可以点（入口不依赖数量）；数量行换成一条骨架灰块（高度与数字行相同，避免加载完跳动）；不显示提醒行。
  - 数量加载失败：数量行显示「—」（`text-tertiary`，读屏读作「数量没有加载出来」）；入口照常可用；页面级另有一条提示条负责说明和重试。
  - 数量为 0：数字照常显示 0，不隐藏卡片，不换成别的文案。
- 键盘：Tab 依次到达每张卡片的标题链接、提醒链接；Enter 进入。

## 19. 编码字段

主数据编码、商品 ID 这类「创建时填一次、以后不能改」的字段。

- **新增时**：普通输入框，等宽字体；`autocapitalize="characters"`、`autocomplete="off"`、`spellcheck="false"`；输入时把小写字母自动转成大写、去掉首尾空格（不改变光标位置）。占位文字放一个格式示例，帮助说明写清格式和「创建后不能修改」。
- **编辑时**：只读样式（底 `bg-subtle`，等宽字体，可以选中复制），右侧有「复制」图标按钮（`aria-label="复制编码"`，复制后发 Toast「已复制」）；帮助说明写「编码创建后不能修改。」。用 `readonly` 而不是 `disabled`（禁用的字段读屏会跳过，且对比度不够）。提交修改时**不带**这个字段。
- 其他「创建后不能改」的字段（国家、类型、等级、座位数、上级）在编辑时同样用只读样式，帮助说明写「创建后不能修改。」；单选组、下拉在只读时改为显示一行文字（当前值），不显示成一组灰掉的选项。


## 20. 地图画布

在地图上看、画、改图形的地方（区域的营运区和禁行区；以后的城市边界、订单的上下车点也用它）。技术选型和底图来源见 [`pages/tenant-areas.md`](./pages/tenant-areas.md) 第 13 节；这里只写它长什么样、怎么响应操作。

**原则：地图只是「看和画」的一种方式，不是唯一的方式。** 任何用到地图画布的页面，都必须另有一个不靠地图就能完成同样事情的控件（坐标表，见第 23 节）。底图加载不出来、没有配置底图、不用鼠标、用读屏，页面都要能完成全部操作。

**容器**

- 底 `bg-subtle`（底图没出来时看到的就是它），边框 `border-default`，圆角 `radius-lg`，`overflow: hidden`；宽度撑满所在栏，`max-width: 100%`。高度由页面定，但不小于 280px。
- 容器是一个 `position: relative` 的框，里面从下到上固定这几层（用 DOM 顺序和地图库自己的分层实现，**不写 `z-index` 数字**；确实需要时只用 `z-base`）：底图 → 参考线（如城市边界）→ 图形的填充 → 图形的描边 → 选中图形的控制点 → 位置标记 → 正在画的图形 → 浮在地图上的控件（缩放、图例、署名、提示）。
- 浮在地图上的控件距容器边缘 `space-2`。四个角的分工固定：**左上**搜索框（有的话）；**右上**缩放和定位按钮；**左下**图例；**右下**署名。任何宽度下互不遮挡，署名永远看得见（第 21 节）。

**图形的画法**（颜色只引用令牌；每一种图形除了颜色，还必须有**线型或纹理**上的区别，并在图例里用文字写明）

- 每条描边都画两遍：下面一条「衬线」用 `bg-surface`、比上面宽 2px；上面一条才是图形自己的颜色。这样不管底图是什么颜色、亮色还是暗色，描边都压在自己的衬线上，对比度由「该颜色在 `bg-surface` 上」保证（都在 `01-tokens.md` 允许的搭配里），不依赖底图。
- 填充用图形自己的颜色加不透明度（`fill-opacity`），不另设颜色令牌。未选中 0.16，选中 0.24。
- 具体到「营运区 / 禁行区」用什么颜色和线型，见 `pages/tenant-areas.md` 第 6 节。
- 图形的颜色、线宽、线型都写在样式文件里（给图形元素加类名，用 `stroke: var(--color-…)`），**不在脚本里写颜色值**，主题切换时自动跟着变。

**控制点**（只有选中的那一个图形显示）

| 元素 | 样子 | 可点范围 |
| --- | --- | --- |
| 顶点 | 直径 10px 的圆，底 `bg-surface`，2px 描边（图形的颜色） | 24×24px；触屏 44×44px |
| 顶点（悬停、拖动中） | 底换成图形的颜色 | 同上 |
| 选中的顶点 | 直径 14px，外面再加 2px 的 `border-focus` 环 | 同上 |
| 边的中点（拖它或点它 = 在这条边上加一个点） | 直径 8px 的圆，底是图形的颜色（不透明度 0.6），1px `bg-surface` 描边 | 24×24px；触屏 44×44px |
| 圆的圆心 | 同顶点，中间加一个 2px 的实心点 | 同上 |
| 圆的半径点（圆的正东方向那一点） | 同顶点 | 同上 |

- 一个图形的顶点超过 200 个时不画中点（太密，点不准），加点改用坐标表。
- 光标：可拖的控制点 `grab`，拖动中 `grabbing`；选中图形的内部 `move`；画图时 `crosshair`。

**图形上的名字**：每个图形在自己内部的一个点上有一个小标签（样式同第 7 节的「标签」：`font-size-xs`、`font-weight-medium`、底 `bg-surface`、边框 `border-default`、圆角 `radius-sm`；字的颜色是图形的颜色），写它在图形列表里的名字（「营运 1」「禁行 2」）。图形在屏幕上比标签还小时不显示标签；选中的图形总是显示。标签不响应点击（点它等于点图形）。

**位置标记**（搜索到的地点、自测的位置）：水滴形图钉，高 24px，底 `primary`，2px `bg-surface` 描边，尖端指着坐标；旁边可以带一个标签（样式同上，字 `text-primary`）。

**缩放和定位按钮**：只有图标的次要按钮，`control-height-md` 见方（触屏自动 44px），纵向排成一组，组内间距 0、共用外边框：放大（`aria-label="放大地图"`）、缩小（`aria-label="缩小地图"`）、与它们隔开 `space-2` 的一到两个「定位」按钮（做什么、`aria-label` 写什么由页面给，如「看全部图形」「回到城市中心」）。到了最大 / 最小级别时对应按钮禁用。

**比例尺**：左下角图例的上方（图例收起时在左下角），公制，`font-size-xs`，`text-primary`，底 `bg-surface`，下边和两端有 1px `text-primary` 的刻度线。

**地图上的提示条**：需要告诉用户「地图现在的情况」时（底图没加载出来、请先选城市、正在画图的操作提示），在地图容器内顶部居中放一条，样式用第 8 节的提示条，左右各留 `space-2`，最大宽度 `min(480px, 100% - 16px)`。操作提示（「点地图加点，点第一个点或按 Enter 完成」）用 `info`；底图问题用 `warning`。它不挡住右上角的按钮：放不下时提示条排在按钮下方。

**状态**

| 状态 | 显示什么 |
| --- | --- |
| 地图库或配置还在加载 | 容器内居中 16px 转圈 +「正在加载地图…」。图形列表和坐标表此时已经可用 |
| 底图加载中（个别瓦片还没到） | 不显示任何加载样式；没到的地方露出 `bg-subtle` |
| **底图加载失败**（网络不通、被拦、瓦片服务不可用） | 容器保留，底是 `bg-subtle`；**图形、控制点、位置标记照常显示，照常可以编辑**；顶部一条警告提示条，文案由页面定，带文字按钮「重试」 |
| **没有配置底图** | 同上，提示条换成信息提示条，没有「重试」 |
| 地图库本身加载失败（脚本没下载下来） | 容器内显示错误状态（第 13 节的版式）：标题「地图没有加载出来」，说明由页面定（要写明「可以用下面的坐标表继续」），次要按钮「重试」 |
| 禁用（前置条件没满足，如还没选城市） | 底图不加载；容器内居中一句说明（`font-size-md`，`text-secondary`）；所有画图工具禁用 |
| 只读 | 可以平移、缩放、点图形看名字；没有控制点，不能拖 |

**暗色**：底图服务给了暗色样式的地址就用它；没有时，只对**底图那一层**加一条滤镜把它压暗（`filter: invert(1) hue-rotate(180deg) brightness(0.95) contrast(0.9)`；滤镜不是颜色，不违反「只引用令牌」）。图形、控制点、标签、控件不加滤镜，它们用暗色令牌。两套主题各看一遍：图形的描边和衬线、标签、图例、署名都要读得清。

**触屏**

- 页面里的地图在触屏上（`pointer: coarse`）**一根手指滑动是滚动页面，不是移动地图**；两根手指移动和缩放地图。地图上方浮一句提示「用两根手指移动地图」（只在用户用一根手指在地图上滑动时出现 2 秒）。这样地图不会把页面的滚动「吃掉」。
- 要在触屏上画图、拖点，先点「放大地图」进入全屏（见下）；全屏里一根手指就是操作地图。
- 双击缩放保留；画图时双击是「完成」，不缩放。

**全屏**：容器右上角按钮组里有「放大地图」（`aria-label="放大地图到全屏"`）。点了以后地图画布连同它的工具条占满整个视口（`100dvh`，用原生 `<dialog>` 的 `showModal()`，规则同第 9 节：焦点限制在内部，Esc 或「退出全屏」按钮关闭，关闭后焦点回到「放大地图」按钮）。全屏只是换了个大小，**图形的数据是同一份**，进出全屏不丢任何东西。底部留出 `env(safe-area-inset-bottom)`。

**键盘与无障碍**

- 地图画布本身是**一个** Tab 停靠点（`tabindex="0"`），有看得见的聚焦环（画在容器内侧，`outline-offset: -2px`）。`role="application"`，`aria-roledescription="地图"`，`aria-label` 由页面给（「区域地图」），`aria-describedby` 指向一段只给读屏的说明：「方向键移动地图，加号减号缩放。图形的坐标可以在后面的坐标表里查看和修改。」
- 画布获得焦点时的按键：

  | 按键 | 做什么 |
  | --- | --- |
  | ↑ ↓ ← → | 移动地图，每次 80px；按住 Shift 每次 240px；按住 Alt 每次 8px |
  | `+` / `=`、`-` | 放大、缩小一级 |
  | `0` | 执行第一个「定位」按钮的动作（它禁用时执行第二个） |
  | Esc | 取消正在画的图形 / 退出当前工具回到「选择」；都没有时不做任何事（全屏时由对话框处理为退出全屏） |
  | 画图工具下的按键 | 见第 22 节 |

- 图形和控制点**不是** Tab 停靠点（可能有几百个）。键盘和读屏用户通过图形列表选中图形、通过坐标表改点（第 23 节）；在列表或表里选中了哪个图形、哪个点，地图上同步高亮并移到看得见的地方。
- 缩放、定位、全屏按钮是普通按钮，排在画布之后的 Tab 顺序里。
- 地图里发生的、看不见就不知道的变化，用一个只给读屏的 `role="status"` 区域播报（「已添加第 4 个点」「营运 1 已完成，共 6 个点」「已撤销」）。
- 设置了「减少动态效果」时：定位、缩放不做飞行动画，直接跳到位。
- 地图画布里的文字（标签、比例尺、署名）最小 `font-size-xs`，随浏览器字号放大。

## 21. 地图的图例与署名

**图例**（左下角）

- 样式：底 `bg-surface`，边框 `border-default`，圆角 `radius-md`，阴影 `shadow-sm`，内边距 `space-2`，最大宽度 `min(240px, 100% - 16px)`。
- 每一项一行：左边一个 24×14px 的小图样（**用和地图上完全相同的画法**：同样的描边颜色、线型、填充、纹理，带衬线）+ 右边文字（`font-size-xs`，`text-primary`）。文字写「它是什么 + 意味着什么」，不只写名字。行间距 `space-1`。
- 图例里只列地图上**现在可能出现**的东西；没有的不列（城市没有边界时不列「城市边界」）。
- 图例里可以带复选框，控制某一类参考内容显不显示（「显示机场和车站」）。
- < 480px 或地图高度 < 360px 时默认收起成一个按钮「图例」（次要按钮，`sm` 尺寸，`aria-expanded`），点了在原地展开，再点收起。展开时不能盖住署名。
- 语义：`<section aria-label="图例">`，里面是 `<ul>`；小图样 `aria-hidden="true"`。

**署名**（右下角）

- 底图的数据来源和版权声明。**只要显示了底图就必须显示，不能收起、不能被别的控件盖住、不能放进要点一下才出来的地方**（这是底图服务的使用条件，见 `pages/tenant-areas.md` 第 13 节）。
- 样式：底 `bg-surface`，圆角 `radius-sm`，内边距 `space-0-5` / `space-1`，`font-size-xs`，字 `text-secondary`，链接 `text-link`；最大宽度是容器宽度减去图例按钮的宽度，放不下时折行。
- 内容来自底图配置（一组「文字 + 链接」），不写死在页面里。链接在新标签页打开，`rel="noopener noreferrer"`，读屏文字带上「（在新标签页打开）」。
- 底图没有加载（失败、没有配置）时不显示署名。

## 22. 绘制工具条

地图画布上方的一行工具（全屏时在地图顶部）。

```
[选择] [画多边形] [画圆] [粘贴坐标]     新图形是： (● 营运区  ○ 禁行区)        [撤销] [重做]
```

（每个按钮都是「图标 + 文字」，图标用第 15 节的线性图标。）

- 容器：`role="toolbar"`，`aria-label="绘制工具"`，`aria-controls` 指向地图画布。底 `bg-surface`，边框 `border-default`，圆角 `radius-md`，内边距 `space-1`，与地图间距 `space-2`；`flex-wrap: wrap`，放不下自动换行。
- **工具按钮**（选择、画多边形、画圆）是互斥的：样式是次要按钮（`md` 尺寸，图标 + 文字）；当前工具底 `primary-subtle`、字 `text-link`、边框 `border-focus`，并设 `aria-pressed="true"`。**当前工具不只靠底色区分**：它的文字前多一个对勾图标。
- **动作按钮**（粘贴坐标、撤销、重做）点一下做一件事，没有「当前」状态。撤销、重做没有可撤销 / 可重做的步骤时禁用。
- **「新图形是」**：一组两个单选（原生 `<input type="radio">`，外观做成并排的两段，`<fieldset>` + `<legend>`）。每一段的文字前有一个和图例相同的小图样。它决定接下来画出来、粘贴进来的图形是哪一类。
- < 480px：工具按钮只显示图标（文字收进 `aria-label` 和气泡提示），「新图形是」单独占一行，撤销 / 重做靠右。每个按钮仍然不小于 44×44px（触屏）。
- 前置条件没满足时（如还没选城市）：选择以外的工具全部禁用，工具条下方一行 `text-tertiary` 的说明写原因（「请先选择城市」）。
- 只读时：整条工具条不显示。

**键盘**

- 工具条是一个 Tab 停靠点，内部用 ← → 移动（roving tabindex），Home / End 到两端；「新图形是」的单选按原生规则用方向键切换，所以它是工具条之后单独的一个 Tab 停靠点。
- 快捷键（**只在焦点位于工具条或地图画布上时生效**，焦点在输入框里时不生效；每个按钮的气泡提示里写出快捷键）：

  | 按键 | 做什么 |
  | --- | --- |
  | `V` | 选择 |
  | `P` | 画多边形 |
  | `C` | 画圆 |
  | `Ctrl`/`⌘` + `Z` | 撤销 |
  | `Ctrl`/`⌘` + `Shift` + `Z`，或 `Ctrl` + `Y` | 重做 |

- **用键盘在地图上画**：选了「画多边形」或「画圆」且焦点在地图画布上时，地图正中出现一个准星（十字，16px，`text-primary` 加 `bg-surface` 衬线）。方向键移动地图（准星不动，等于移动准星指着的位置）。

  | 按键 | 画多边形 | 画圆 |
  | --- | --- | --- |
  | 空格 | 在准星处加一个点 | 第一次：定圆心；第二次：准星到圆心的距离定为半径，完成 |
  | Enter | 完成（闭合）；不到 3 个点时不完成，并播报「至少要 3 个点」 | 同空格 |
  | Backspace | 去掉刚加的那个点 | 去掉圆心，重新定 |
  | Esc | 取消这个图形 | 取消这个图形 |

  用鼠标时不显示准星。Enter、Backspace、Esc 对鼠标画图同样有效。

## 23. 图形列表与坐标表

和地图画布成对出现：地图上的每一个图形，在这里都有一项；地图上能做的每一件事，在这里都有不靠鼠标的做法。

```
营运区（2）                                         [+ 添加营运区 ▾]
┌──────────────────────────────────────────────────────────────┐
│ ▾ ▬ 营运 1   多边形 · 6 个点 · 约 12.4 平方公里          [更多]  │
│   #   纬度          经度                                       │
│   1  [35.689500 ] [139.691700 ]   [+] [×]                     │
│   2  [35.701200 ] [139.745300 ]   [+] [×]                     │
│   …                                                          │
│   [+ 加一个点]  [粘贴坐标替换]                                   │
├──────────────────────────────────────────────────────────────┤
│ ▸ ▬ 营运 2   圆 · 半径 3 公里                            [更多]  │
└──────────────────────────────────────────────────────────────┘
禁行区（1）                                         [+ 添加禁行区 ▾]
┌──────────────────────────────────────────────────────────────┐
│ ▸ ▨ 禁行 1   多边形 · 4 个点   ! 有 1 处需要修改          [更多]  │
└──────────────────────────────────────────────────────────────┘
```

**分组**

- 按类型分成几组（区域页是「营运区」「禁行区」两组，顺序固定），每组一个标题行：组名 + 括号里的个数（`<h3>`，`font-size-md`，`font-weight-bold`）+ 右侧「添加」按钮（次要按钮，`sm` 尺寸，带下箭头，点开是菜单；菜单里的项由页面定）。达到个数上限时按钮禁用，旁边写「最多 N 个」。
- 一组里一个图形都没有：标题行下面一句 `text-tertiary` 的说明（由页面定），不画空的框。

**一项（一个图形）**

- 外框：同一组的项连在一起，共用一个外框（边框 `border-default`，圆角 `radius-lg`），项与项之间用 `border-default` 分隔。
- **标题行**是一个 `<button aria-expanded>`，点它展开 / 收起这个图形的坐标表，同时**选中这个图形**（地图上高亮并移到看得见的地方）。内容从左到右：展开箭头（16px）、小图样（和图例相同）、名字（`font-weight-medium`）、一行说明（`font-size-sm`，`text-secondary`：形状 · 点数或半径 · 面积）、问题提示（有才显示）。高度不小于 `table-row-height`。
- 选中的那一项：标题行底 `bg-selected`，左侧 3px `primary` 竖条，`aria-current="true"`。同一时间只有一个图形是选中的；在地图上点了某个图形，这里对应的项跟着选中、展开、滚到看得见的地方。
- **问题提示**：这个图形有不改就不能保存的问题时，标题行里显示警示图标 +「有 N 处需要修改」（`danger-text`）；只是提醒、不妨碍保存时显示三角图标 + 提醒的第一句（`warning-text`）。完整的说明在展开后的坐标表下方。
- 标题行右侧的「更多」按钮（只有图标，`aria-label="{名字} 的更多操作"`）打开菜单；菜单项由页面定（改名、换类型、整体移动、删除等）。危险的菜单项（删除）字色 `danger-text`，排在最后，上面有分隔线。
- 新加的图形默认展开并选中；其余默认收起。

**坐标表**（展开后；多边形用）

- 是一张真正的 `<table>`，`<caption>`（只给读屏）写「{名字} 的顶点坐标」。列：序号（`<th scope="row">`，等宽数字，`text-secondary`）、纬度、经度、操作。**纬度在前、经度在后**（`04-data-display.md` 第 6 节）。表头吸在表格容器顶部。
- 每个顶点一行。**首尾闭合的那个重复点不显示**：表里有几行，多边形就有几个顶点；最后一行自动连回第 1 行。
- 纬度、经度各是一个输入框：`sm` 尺寸，等宽字体，`type="text"`、`inputmode="text"`、`autocomplete="off"`、`spellcheck="false"`；`aria-label="第 N 个点的纬度"`。规则与 `pages/master-data.md` 5.8 的坐标输入相同（失去焦点时整理成 6 位小数；出错文字相同）。
- **什么时候生效**：一个格子里的值在失去焦点或按 Enter 时生效（合法才生效），地图立即跟着变；正在打字的过程中不动地图。地图上拖了点，表里对应的格子立即跟着变。
- **行与地图的对应**：焦点进入某一行时，地图上对应的顶点显示为「选中的顶点」，不在视野里就把地图移过去；在地图上点了某个顶点，表里对应的行滚到看得见的地方并加 `bg-selected` 底色（不抢焦点）。
- **行尾两个只有图标的按钮**：「在第 N 个点后面加一个点」（加号；新行的初始值是这个点和下一个点的中点，焦点进入新行的纬度框）、「删除第 N 个点」（×）。只剩最少点数（多边形 3 个）时删除按钮禁用，`title` 写「至少保留 3 个点」。
- 表格下方：「加一个点」（次要按钮，`sm`；加在最后，初始值是最后一个点和第 1 个点的中点）、「粘贴坐标替换」（文字按钮；打开页面定义的粘贴对话框）。达到顶点上限时「加一个点」和行尾的加号禁用，旁边写「最多 N 个点」。
- **粘贴**：
  - 在某个格子里粘贴一对数字（「35.6895, 139.6917」，逗号、空格、制表符分隔，全角逗号也认）：拆开填进这一行的两个格子。
  - 在某个格子里粘贴**多行**（每行一对数字，如从表格软件里复制的两列）：第一对填进当前行，其余各对依次在它后面插入新行。粘贴后在表格下方用信息色的一行写「已粘贴 N 个点。」
  - 顺序默认是「纬度, 经度」；能判断出是经度在前时自动对调并提示（判断办法由页面定）。
  - 有任何一行解析不出来：整次粘贴都不生效，表格下方出错文字写「第 M 行不是一对坐标：{那一行的前 30 个字}」。
- 行数多时：一次最多显示 100 行，表格下方「第 1–100 个点，共 N 个」和「上一段」「下一段」（`sm` 次要按钮）。在地图上点了不在当前这一段的顶点，自动切到它所在的那一段。
- 校验文字的位置：某一格的问题（不是数字、超出范围）在那一行下方，只标红那一格；属于整个图形的问题（边交叉、点太少）在表格下方，用字段出错文字的样式（图标 + `danger-text`），每个问题一行，问题里提到的点号是按钮，点了跳到那一行。
- 表格容器：`overflow-x: auto`，最大高度 320px（内部纵向滚动），`tabindex="0"`、`role="region"`、`aria-label` 同 caption。

**圆的字段**（展开后；圆用，代替坐标表）：三个输入框排成一行——圆心纬度、圆心经度、半径（带单位后缀）；< 480px 时纬度、经度一行，半径一行。下面一个文字按钮「转成多边形」（转了以后就能逐点修改，也就不再是圆）。

**只读**：没有「添加」、行尾按钮、「更多」里的修改项；输入框换成只读样式的文字（等宽，可以选中复制）；标题行仍然可以展开和选中。

**手机宽度**

- 整个列表撑满宽度；标题行的说明折到名字下一行。
- ≥ 480px：坐标表一行一个点，两个输入框等分宽度（`minmax(0, 1fr)`），序号列和操作列固定宽度。
- < 480px：一行放不下（320px 宽的屏上，去掉页面边距和卡片内边距只剩 256px，而触屏的输入框是 16px 字、行尾两个按钮各 44px）。**每个点排成两行**：第一行左边「第 N 个点」（`font-size-sm`，`text-secondary`），右边行尾的两个按钮；第二行纬度、经度两个输入框等分宽度（各约 124px，放得下 `-123.456789` 这 11 个字符）。不显示表头，输入框内用前缀文字标明「纬度」「经度」的做法**不用**（会挤掉数字的位置）——改为每个输入框上方保留一行很小的标签（`font-size-xs`，`text-tertiary`）。点与点之间用 `border-default` 分隔。用样式把表格行重排时，给行和单元格补上 `role="row"`、`role="cell"` / `role="rowheader"`，保住表格语义。
- 任何宽度下，坐标表都不让页面横向滚动。

**键盘与无障碍**

- Tab 顺序：组的「添加」→ 每一项的标题按钮 →「更多」→（展开时）表里逐格、行尾按钮 → 表格下方的按钮。
- 删除一行后焦点移到下一行的纬度框，没有下一行就移到上一行；加一行后焦点进入新行的纬度框。
- 表格里 Enter 让当前格生效并把焦点移到下一格（纬度 → 经度 → 下一行纬度），在最后一行的经度按 Enter 不自动加行。
- 图形被删除、被加入、点数变化时，用 `role="status"` 播报（「已删除营运 2」「营运 1 现在有 7 个点」）。

## 24. 步骤导航

一件事要分几步配完、每一步单独保存、可以来回跳时用（商品的「基础信息 → 服务规则 → 价格规则 → 库存 → 商品详情 → 上架检查」）。它和页签（第 10 节）的区别：页签是平级的分区，没有顺序和完成情况；步骤导航有建议的顺序，并且**每一步做完没有一眼看得见**。有完成情况要显示的地方用步骤导航，不用页签。

```
配置步骤                已完成 1 / 5
▌① 基础信息
   ✓ 已完成
 ② 服务规则
   ! 还差 2 项
 ③ 价格规则
   ◷ 即将开放
──────────────────────
 上架检查
   ! 还不能上架
```

- 容器：卡片样式（`03-layout.md` 第 2 节），内边距 `space-3`。标题行：左边标题（`font-size-sm`，`font-weight-medium`，`text-secondary`），右边总进度「已完成 {K} / {N}」（`font-size-sm`，`text-secondary`，等宽数字）。
- 语义：`<nav aria-label="{标题}">` 里一个 `<ol>`；每一步是一个 `<li>`。不属于编号步骤的收尾项（「上架检查」）放在同一个 `<nav>` 里的第二个列表，上面一条 `border-default` 分隔线。
- **一步**：两行。第一行序号（带圈数字的写法「①」，`aria-hidden`，读屏用「第 1 步」）+ 步骤名（`font-size-md`）；第二行状态（16px 图标 + 文字，`font-size-sm`），缩进到和步骤名对齐。整项最小高度 `control-height-lg`，内边距 `space-2` / `space-3`，圆角 `radius-md`。
- 可以进入的步骤是一个 `<a>`（整项可点）；悬停底 `bg-hover`。
- **当前步骤**：底 `primary-subtle`，步骤名字 `text-link` + `font-weight-medium`，左侧 3px `primary` 竖条，`aria-current="step"`（和侧边栏的「当前页」同一套画法）。状态那一行的颜色不变。
- **状态一行**：每种状态用**不同形状的图标 + 文字**，颜色只是辅助。常用的几种：

  | 状态 | 图标 | 颜色 |
  | --- | --- | --- |
  | 已完成 | 对勾 | `success-text` |
  | 还差 N 项 | 三角警示 | `warning-text` |
  | 还没开始 / 未保存 | 空心圆 | `text-tertiary` |
  | 要先做完前面的才能进 | 锁 | `text-tertiary` |
  | 还没上线（「即将开放」） | 时钟 | `text-tertiary` |
  | 在等别的事 | 时钟 | `info-text` |

  状态文字由页面给。当前步骤的底是 `primary-subtle`（= `bg-selected`），上表的颜色放在它上面都在允许的搭配里。
- **不能进入的步骤**（锁着的、还没上线的）：不是链接，是一段普通文字（`<span>`），步骤名字 `text-tertiary`，`cursor: default`，没有悬停效果，**不是 Tab 停靠点**，但不加 `aria-hidden`——读屏按顺序读得到「第 3 步，价格规则，即将开放」。不用 `text-disabled`（它要被读到）。为什么不能进入，写在导航下方的一段固定文字里（`font-size-sm`，`text-tertiary`，内边距同步骤项），不放在气泡里。
- 完成情况加载中：步骤名照常显示并且可以点，状态一行是骨架灰块；加载失败：状态一行显示「—」。
- **窄屏（< 1024px）收成一个按钮**：`<button aria-expanded aria-controls>`，撑满宽度，次要按钮的样子，高度不小于 `control-height-lg`，内容左对齐、可折成两行：「第 {i} 步，共 {N} 步 · {步骤名} · {状态文字}」+ 右侧 16px 下箭头。点开后在按钮下方原地展开成上面的竖排清单（不是浮层，把下面的内容推下去），点任一步或再点按钮后收起。收尾项是当前页时写「{收尾项的名字} · {状态文字}」。
- 键盘：每个可以进入的步骤是一个 Tab 停靠点，Enter 进入；不用方向键（它是链接的列表，不是页签）。换步骤后焦点移到新步骤内容的标题上。
- 步骤最多 7 个；更多说明这件事该拆开了。

## 25. 检查清单

告诉人「要达到某个目标，哪些条件满足了、哪些没有、没有的去哪改」（商品的上架检查；以后的资质认证、供应商入驻也用它）。

```
┌───────────────────────────────────────────────────────────┐
│ ✓ 基础信息      已满足                                       │
├───────────────────────────────────────────────────────────┤
│ ! 服务规则      还差 2 项                           [去修改] │
│     · 还没有填服务时间                               去填 ›  │
│     · 还没有填提前预订时长                            去填 ›  │
├───────────────────────────────────────────────────────────┤
│ ◷ 价格规则      功能即将开放                                 │
│     不是出错：……                                           │
└───────────────────────────────────────────────────────────┘
```

- 容器：一组检查项共用一个外框（边框 `border-default`，圆角 `radius-lg`），项与项之间用 `border-default` 分隔。有几组时每组上面一个小标题（`<h3>`，`font-size-md`，`font-weight-bold`），组间距 `space-4`。语义是 `<ul>`。
- **一项**：内边距 `space-3`。第一行从左到右：20px 状态图标、项名（`font-size-md`，`font-weight-medium`，`text-primary`）、状态文字（`font-size-sm`，`font-weight-medium`）、行尾最多一个次要按钮（`sm`，是一个 `<a>`）。第一行下面是展开的内容，缩进到和项名对齐。
- **四种状态**，图标形状、文字、颜色三样都不同：

  | 状态 | 图标 | 颜色（图标和状态文字） | 展开的内容 |
  | --- | --- | --- | --- |
  | 满足了 | 圆圈里的对勾 | `success-text` | 无 |
  | 还没满足，用户自己能补 | 三角警示 | `warning-text` | 原因的列表（嵌套的 `<ul>`），每条 `font-size-sm`、`text-primary`，后面跟一个去到对应位置的链接（`text-link`，带向右箭头） |
  | 还没满足，但不是用户的事（功能没上线、在等别人审核） | 时钟 | `info-text` | 一段说明（`font-size-sm`，`text-secondary`），第一句先说「不是出错」 |
  | 不是必须 | 短横线 | `text-tertiary` | 一句说明 |

  - 「还没满足」用警告色，不用危险色：危险色留给「做错了、失败了」。
  - 所有项都不用底色铺满整行；只有图标和状态文字带颜色，正文是 `text-primary` / `text-secondary`，放在 `bg-surface` 上（都在允许的搭配里）。
- 状态文字由页面给，同一张清单里不同状态的文字必须不同。
- 清单上方通常配一条总结用的提示条（第 8 节），用一句话回答「现在行不行」；清单下方是要做的那个动作的按钮。按钮因为条件没满足而禁用时，旁边必须写原因（第 1 节），并且用 `aria-disabled` 而不是 `disabled`，让键盘到得了、读屏读得到。
- 加载中：项名照常显示（清单有哪些项通常是固定的），图标和状态文字是骨架；加载失败：整张清单换成错误状态（第 13 节）。
- 窄屏：状态文字放不下时折到项名下面；行尾的按钮换到这一项的最下面、撑满宽度；原因和它的链接放不下一行时链接折到下一行。
- 读屏：每一项读作「{项名}，{状态文字}」；链接的 `aria-label` 带上它要解决的那条原因。结果刷新后用 `role="status"` 播报总结。

## 26. 可排序的已选列表

从一批选项里选出若干个，而且**选出来的每一个还要再看、再调**（排顺序、给每一个再选一个值）时用——商品的服务区域（要排优先级）、车型组（每个要再选一个「人数 / 行李数」组合）。只是选几个、不用再调的，用组合框的多选（第 3 节），不用它。

```
服务区域 *                                      [+ 添加区域]
┌─────────────────────────────────────────────────────────┐
│ 1  东京 23 区      通用                     [↑] [↓] [×]  │
├─────────────────────────────────────────────────────────┤
│ 2  成田机场周边     接送机   ● 已停用         [↑] [↓] [×]  │
└─────────────────────────────────────────────────────────┘
帮助说明……
```

- 外层 `<fieldset>` + `<legend>`（字段标签，必填带星号）。标签行右侧是「添加{对象}」（次要按钮，`sm`，带加号）。达到上限时按钮禁用，旁边写「最多 N 个」。
- **「添加」打开一个多选面板**：组合框的面板样式（第 3 节），顶部一个搜索框，下面每个选项一行「复选框 + 名称 + 补充信息」；已选的是勾着的，取消勾选 = 移除。面板在点外面、按 Esc、点底部的「完成」（< 480px 才有）时关闭，关闭后焦点回到「添加」按钮。面板底部可以有一行链接（由页面给，如「去新增区域」）。新勾选的按勾选的先后加到列表末尾。
- **已选列表**：`<ol>`（可排序时）或 `<ul>`。外框和分隔线同检查清单。每一行最小高度 `table-row-height`，内边距 `space-2` / `space-3`：
  - 可排序时最左边是序号（等宽数字，`text-secondary`，固定宽 `space-6`）；
  - 名称（`font-weight-medium`，可以是链接），后面跟标签和徽标（第 7 节）；
  - 这一行自己的附加控件（如一个下拉），放在名称下面一行；
  - 行尾的按钮，都是只有图标的文字按钮：可排序时「上移」「下移」（上、下箭头；`aria-label="把 {名称} 上移"`）、「移除」（×；`aria-label="移除 {名称}"`）。第一行的「上移」、最后一行的「下移」禁用。
- **排序只靠按钮，不要求拖动**：按钮在鼠标、触屏、键盘上都一样好用。（以后要加拖动，只能是按钮之外多一种办法，不能代替按钮。）
  - 移动后焦点跟着这一行走（留在同一个按钮上；那个按钮到头被禁用时移到另一个方向的按钮上）。
  - 快捷键：焦点在某一行的任一按钮上时，`Alt` + `↑` / `↓` 移动这一行。
  - 每次移动用 `role="status"` 播报「{名称} 现在排第 {i}，共 {N} 个」。
  - 移动没有动画（设置了「减少动态效果」时本来也不该有），行直接换位置。
- 移除后焦点移到下一行的「移除」按钮，没有下一行就移到上一行的，都没有了就移到「添加」按钮。移除不用确认，不发 Toast（还没保存，随时能加回来）。
- 空的时候：不画空的外框，在标签行下面写一行 `text-tertiary` 的说明（由页面给，如「还没有选区域」）。
- 一个可选的都没有时（不是没选，是没得选）：不显示「添加」按钮，换成一个说明块——底 `bg-subtle`，边框 `border-default`，圆角 `radius-md`，内边距 `space-3`；左侧 16px 三角图标（`warning-text`），右侧文字（`text-primary`，第一句加粗）和最多三个按钮（次要按钮 `sm` 或文字按钮）。文字写清「为什么没得选 + 去哪里解决」。
- 前置条件没满足（要先选别的字段）：不显示列表和按钮，只写一行 `text-tertiary` 的「先选{什么}，这里会列出可以用的{对象}。」
- 行里的某一项有问题但不妨碍保存（已停用等）：行内用徽标标出来，列表下方一行警告色的汇总（三角图标 + `warning-text`）。
- 只读：没有「添加」和行尾按钮，序号保留。
- 窄屏（< 480px）：每行折成两行——名称、标签在第一行（名称可折行），行尾按钮在第二行右对齐；行内的附加控件撑满宽度。
- 提交时保持用户看到的顺序。

## 27. 时间与日期输入

填一天里的时刻、每天重复的时段、日期、日期范围时用。**不用浏览器自带的 `type="time"` 和 `type="date"`**：它们的显示格式跟着操作系统的语言走（有的显示上午 / 下午、有的把年份放在后面），和 `04-data-display.md` 第 3 节规定的「24 小时制、`YYYY-MM-DD`」对不上。这里用普通输入框加整理和校验。想在日历上点选日期时，旁边另给一个「在日历上选」的按钮，打开小月历面板（第 32 节）——它是多出来的办法，日期永远可以直接敲。

**时刻**

- 输入框：`type="text"`、`inputmode="numeric"`、`autocomplete="off"`，等宽数字（`tabular-nums`），宽度不小于 5 个字符加左右内边距；占位文字是一个例子（「08:00」）。
- 失去焦点时整理成 `HH:mm`：`9`、`09` → `09:00`；`930`、`0930`、`9:30`、`9：30`（全角冒号）、`9.30` → `09:30`。整理不出来的不动它并报错：「请填时间，例如 08:00」。范围 00:00 到 23:59。

**时段**（每天从几点到几点）

```
服务时间 *
从 [ 22:00 ]  到 [次日 06:00 ]     ☐ 全天 24 小时
每天 22:00–次日 06:00，共 8 小时（跨午夜）
```

- 外层 `<fieldset>` + `<legend>`。两个时刻输入框，前面各有可见的标签「从」「到」（`font-size-sm`，`text-secondary`），中间间距 `space-2`；≥ 480px 两格各宽 `min(120px, 100%)`，更窄时等分一行。
- **跨午夜不用另外勾选**：结束早于开始就是到第二天。这时「到」的输入框内左侧出现前缀「次日」（第 2 节的前缀样式）。
- **读回来的话**：两格都合法后，下方一行（`font-size-sm`，`text-secondary`，`aria-live="polite"`，输入停下 500ms 后更新）把时段按 `04-data-display.md` 第 3 节的写法读回来，并写出时长；跨午夜的在最后加「（跨午夜）」。它是必须有的：跨午夜靠「结束比开始早」来表达，用户需要看到系统是怎么理解的。
- 开始和结束相同：报错（文字由页面给）。
- **两头算不算在内由页面定，并且必须写在帮助说明里**：服务时间是两头都算；调价规则的时段是开始算、结束不算（这时「到」可以填 `24:00`，表示到当天结束）。同一个控件，两种算法，不写明就一定有人填错。
- 可选的「全天 24 小时」复选框（页面决定有没有）：勾上后两格变成只读并显示「00:00」「24:00」，读回来的话写「全天 24 小时」；取消勾选恢复成勾之前的值。
- 出错文字显示在整组下方（读回来的话的位置），只标红出错的那一格。

**日期**

- 输入框：`type="text"`、`inputmode="numeric"`、`autocomplete="off"`，等宽数字，占位文字「2026-01-31」这种例子（用页面给的例子，不是今天）。
- 失去焦点时整理成 `YYYY-MM-DD`：`20261008`、`2026/10/8`、`2026.10.08`、`2026-10-8` 都认。不是真实存在的日期（2 月 30 日）或整理不出来：「这不是一个日期，请按 2026-10-08 的格式填写」。

**日期范围**：两个日期输入框，标签「从」「到」，排法同时段。「到」早于「从」：整组下方「结束日期不能早于开始日期」，标红「到」。两格都可以单独留空时，由页面说明留空的意思。读回来的话按「2026-03-01 至 2026-03-31」的写法；只填了一头的写「从 2026-03-01 起」/「到 2026-03-31 为止」；两头都可以留空而且都空着时，写页面给的那句话（如「不限日期」）。

- 这些时间属于哪个时区，由页面在显眼的地方写明（`04-data-display.md` 第 4 节）；输入框本身不带时区。
- 只读：显示成一行文字（读回来的话那种写法）。

## 28. 可选规则块

一组字段整体是「可以不要」的，而且随表单一起保存时用（商品的加急预订、夜间加价）。

```
┌──────────────────────────────────────────────┐
│ ☑ 允许加急预订                                 │
│ 开启后，客人在提前预订时长以内也能下单……          │
│ ──────────────────────────────────────────── │
│ 每日加急库存 * [      ] 单 / 天                 │
│ 加急阶梯 *  ……                                │
└──────────────────────────────────────────────┘
```

- 容器是一张卡片。**卡片的标题就是一个复选框**（第 3 节：随表单一起保存的开 / 关用复选框，不用开关）：复选框 + 标签（卡片标题的字号和字重），标签写成一句说得出「勾上是什么意思」的话（「允许加急预订」「收夜间加价」），不写「启用」。
- 标题下面一行说明（`font-size-md`，`text-secondary`），**勾不勾都显示**：写清勾上会怎样、不勾会怎样。
- 勾上：说明下面一条 `border-default` 分隔线，然后是里面的字段。不勾：分隔线和字段都不显示（从 DOM 里去掉，不是藏起来），卡片就只有标题和说明两行。展开、收起不做高度动画。
- 复选框带 `aria-expanded` 和 `aria-controls`。勾上后焦点留在复选框上，不自动跳进字段。
- 里面的字段有内容时取消勾选：字段先不清空（再勾上还在），块的下方用信息色写一行「保存后，这里填的内容会清除。」保存成功后才真的清掉。
- 里面的必填字段只在勾上时才算必填。
- 只读：勾着的显示标题（没有复选框，标题后面一个标签「已开启」）和里面的只读内容；没勾的显示标题和一行「没有开启」。

## 29. 金额输入

填一笔钱时用（价格、调价步骤、加急费、夜间加价、附加服务单价）。显示和校验的规则在 `04-data-display.md` 第 1 节「输入金额」，这里写控件本身。

```
基础价 *
[        20,000 ] JPY          ← 失去焦点：带千分位、右对齐
[ 20000|        ] JPY          ← 聚焦：纯数字、全选
```

- 是第 2 节的输入框：`type="text"`（**不用 `type="number"`**），`autocomplete="off"`，等宽数字（`tabular-nums`），**数字右对齐**。
- **币种**：结算币种的三位代码作后缀（第 2 节的后缀样式，`text-secondary`），带单位时写「JPY / 公里」「JPY / 小时」。币种由子品牌决定，这里不能改。放在表格里时（第 30 节）币种写进表头，格子里没有后缀。
- **小数位跟着币种走**（`@nozomi/domain` 的 `CURRENCIES`）：没有小数的币种 `inputmode="numeric"`；有小数的 `inputmode="decimal"`，只填整数的失去焦点后补齐小数位。小数位超了**报错，不自动四舍五入、不自动截掉**（「日元金额不能有小数」「{币种} 最多 {N} 位小数」）。
- **千分位**：聚焦时是纯数字并全选（方便直接重填）；失去焦点后显示带千分位的写法。输入过程中不插逗号。
- **整理**（失去焦点和粘贴时）：去掉逗号、空格、币种代码和符号（`JPY`、`¥`、`円`、`元`、`￥`）；全角数字和全角小数点换成半角。整理不出数字的不动它并报「请填数字」。
- 默认不能为负（「{字段名}不能是负数」）。要表达「减」的地方（调价步骤）用旁边的「上调 / 下调」下拉，不让人敲负号。
- 能不能填 0、0 是什么意思，由页面定，并且写在帮助说明或读回来的话里（「0 = 不另收」「免费提供」）。
- 字符串和金额之间的转换只用 `parseMajor` / `formatMajor`，不用浮点数；上限由页面给（来自 `@nozomi/domain`），`maxlength` 按上限的位数加千分位和小数留够。
- 宽度：单独使用时 `min(200px, 100%)`；在一行里和别的格子并排时等分。窄屏撑满。
- 出错、禁用、只读同第 2 节；只读时显示成带币种的文字（`JPY 20,000`）。
- 读屏：`aria-label` 或 `<label>` 里带上币种（「基础价，日元」用币种代码即可：「基础价（JPY）」）；出错文字用 `aria-describedby` 关联。

## 30. 可编辑表格

一批结构相同的记录要**连着改很多条、最后一起保存**时用（价格规则）。只改一两条、或每条字段很多的，用列表 + 单独的编辑页，不用它。

```
┌───┬─────────┬────────┬───────────┬────────────┬─────┬─────────────┬───┐
│ ☐ │ 区域     │ 车型组  │基础价（JPY）│ 生效日期 从  │ 启用 │             │   │
├───┼─────────┼────────┼───────────┼────────────┼─────┼─────────────┼───┤
▌ ☐ │ 东京23区 │ 舒适5座 │[  15,000] │[2026-10-10]│ ☑   │● 改过，未保存 │ ⋯ │
│ ☐ │         │ 豪华4座 │[        ] │[2026-10-08]│ ☑   │! 没有价格    │ ⋯ │
└───┴─────────┴────────┴───────────┴────────────┴─────┴─────────────┴───┘
这一行的意思：东京 23 区 · 舒适 5 座——每单 JPY 15,000 ……
```

- 是第 5 节的表格（容器、表头、对齐、横向只在容器里滚动都一样），区别在于单元格里放的是控件。真正的 `<table>`；**不做成 `role="grid"`**：每个输入框本来就是 Tab 停靠点，读屏用表格导航读得到行头列头。
- **单元格里的控件**：第 2、3、27、29 节的输入框、原生下拉、复选框，尺寸 `control-height-sm`（触屏仍是 44px），撑满单元格；单元格内边距 `space-1` / `space-2`。输入框平时边框用 `border-default`（一屏几十个输入框都用 `border-strong` 会太花），悬停和聚焦时换成第 2 节的样式；它的底是 `bg-surface`、行悬停时不变色，所以不靠边框也认得出是输入格。每个控件都有 `aria-label`「{行的名字}，{列名}」。
- **列头**带单位和币种（「基础价（JPY）」「起步里程（公里）」）。需要解释的列，列名后面一个「说明」图标按钮，点开是小面板（下拉面板样式；不是悬停气泡，触屏也要能看）。
- **身份列**（说明这一行是谁的那几列）是文字，不能在行里改，吸在左边；其中第一个身份列合起来是 `<th scope="row">`。
- **占位行**：页面可以把「应该有、但还没有」的记录画成空行，等人直接填（不用点「新增」）。占位行没填任何东西时不算修改、不提交。
- **行的状态**：倒数第二列，图标 + 文字，一行只显示一种（页面定优先顺序）。有未保存修改的行，行首 3px `primary` 竖条；出错的行，行首 3px `danger-solid` 竖条。竖条只是辅助，状态必须有文字。「将删除」的行：控件变只读、文字加删除线，状态列有「撤销」。
- **出错**：出错的格子用输入框的出错样式；**出错文字不在格子下面展开**（行高不能跟着跳），显示在状态列（第一条）和「当前行说明」里（全部）。保存时有错：焦点到第一处，页面级提示条逐条列出并能跳过去。
- **当前行说明**（表格容器下方固定的一条）：底 `bg-subtle`，圆角 `radius-md`，内边距 `space-2` / `space-3`，`font-size-sm`，`text-primary`，最多三行、超出自己纵向滚动；`aria-live="polite"`，焦点换行或输入停下 500ms 后更新。内容由页面给：用一句人话把当前行读回来，后面跟这一行的全部出错文字和可以一键解决的按钮。焦点不在表格里时保留最后那一行的内容。它是可编辑表格**必须有的部分**：格子里只有数字，人需要一个地方确认「系统是怎么理解这一行的」。
- **键盘**：`Tab` / `Shift` + `Tab` 横着走；输入框里 `Enter` / `Shift` + `Enter` 到下一行 / 上一行的同一列（输入法正在组字时不触发；到头不动）；`Esc` 把这一格还原成聚焦前的值。下拉、复选框上的按键不拦截。
- **粘贴一片**：在输入格里粘贴多行多列的内容（换行分行、Tab 分列），从这一格起向右、向下依次填进现在显示的行，超出的丢掉；填不进去的（不是数字）跳过。粘贴后必须有一句结果（提示条 + `role="status"`）和「撤销这次粘贴」。只粘贴一个值时是普通粘贴。
- **多选和批量**：首列复选框（第 5 节）；`Shift` 连选。选中后表格上方的工具区显示「已选 {N} 条」和批量按钮，放不下时收进「批量操作」菜单。批量操作只改页面上的内容，不直接保存；做完用 `role="status"` 说结果，焦点到第一条被改的行，并提供「撤销」（只退最近一次）。
- **保存**在页面的操作区（一次提交全部修改）。有未保存的修改时离开要确认。
- 分组：按第一个身份列分组时，组里只有第一行显示它的名字（其余行用视觉隐藏的文字保留给读屏），组与组之间用 `border-strong` 的横线。
- 加载中：表头 + 骨架行。只读：没有多选列和操作列，控件显示成文字（金额右对齐、带千分位）。
- **窄屏（< 768px）不用它**：换成每条记录一张卡片（卡片上是读回来的那句话和「改」按钮），点了从底部升起一个表单对话框；对话框的确定只是写回页面，仍然由页面的「保存」提交，对话框里要写明这一点。

┌──────────┬───────────┬───────────┬───────────┐
│          │ 舒适 5 座  │ 商务 7 座  │ 豪华 4 座  │
│ 东京 23 区│    15,000 │    20,000 │ ! 没有价格 │
│ 成田周边  │    22,000 │ ! 没有价格 │ ! 没有价格 │
└──────────┴───────────┴───────────┴───────────┘
```

- 容器是一张卡片。标题行是**一句总结**（由页面给；有缺口时带三角图标，缺的那半句用 `warning-text`；都齐了用对勾 + `success-text`）+ 右侧「收起 / 展开」（`aria-expanded`，状态存在浏览器本地）。收起时只剩这句话——这句话本身就要说清「缺多少」。
- 第三个维度（方向、套餐）用表格右上方的单选组「看：」切换，每个选项后面带它自己缺的个数（「送机（缺 4）」）；多于 4 个选项时换成原生下拉。
- 表格：真正的 `<table>`，行头列头是 `<th>`（列头最多两行，超出省略，`title` 放全文）；容器最高 `min(60dvh, 480px)`，自己纵横滚动，表头和第一列吸住（`z-sticky`）；容器 `tabindex="0"`、`role="region"`、`aria-label`。格子最小宽 `space-16` 的 1.5 倍（96px），高 `table-row-height`（有第二行小字时自动增高）。
- **格子是一个 `<button>`**，撑满单元格，点了去到能改它的地方（由页面定）。`aria-label` 把行、列、第三个维度和状态都读出来。
- 格子的状态，**文字 + 图标，不只靠颜色**：

  | 状态 | 显示 | 样式 |
  | --- | --- | --- |
  | 有 | 值（金额右对齐、等宽数字、不带币种；币种在总结里或表的标题里写一次） | 底 `bg-surface`，字 `text-primary` |
  | 有，但要留意（快到期、以后才生效、用的是通用值） | 值 + 第二行小字（图标 + 文字，`font-size-xs`） | 小字按含义用 `warning-text` / `info-text` / `text-tertiary` |
  | **缺** | 三角图标 +「没有{什么}」；可以有第二行小字说明原因 | 底 `warning-bg`，图标和字 `warning-text`，小字 `text-primary`（都在允许的搭配里）。**不用危险色**：缺不等于错 |
  | 有未保存的修改 | 按修改后的样子显示，最下面多一行小字「未保存」 | 小字 `font-size-xs`，`text-primary`（它可能落在 `warning-bg` 上，所以不用别的状态色） |

  悬停：格子加 `border-strong` 内描边（不换底色，免得盖掉「缺」的底色）；聚焦环照常。
- 跟着页面上现在的内容实时变，不等保存。
- 加载中：行头列头照常，格子是骨架。行数很多（页面给阈值）时默认收起。
- **窄屏（< 768px）不画二维表**：按行的维度分组成列表——组标题是行头 + 这一组缺几个，组里每个列头一行（左边名字，右边值或「没有{什么}」），整行是按钮。组多时默认只展开有缺口的。

## 32. 月历与日期范围选择

按月看每天的一个值，并且能在上面选日期时用（价格日历；以后的库存日历）。两种尺寸：**大月历**（页面的主体，每格放得下两三行内容）和**小月历面板**（从日期输入旁边的「在日历上选」打开，只有日期数字，用来点选日期）。

```
[‹]  2027 年 10 月  [›]   [回到本月]
┌──────┬──────┬──────┬──────┬──────┬──────┬──────┐
│ 周一  │ 周二  │ 周三  │ 周四  │ 周五  │ 周六  │ 周日  │
├──────┼──────┼──────┼──────┼──────┼──────┼──────┤
│      │      │      │      │ 1 起  │ 2    │ 3 止  │   ← 选中的一段：底 bg-selected，两头有文字
│      │      │      │      │24,000│24,000│24,000│
└──────┴──────┴──────┴──────┴──────┴──────┴──────┘
```

- **月份条**：「上个月」「下个月」图标按钮（`aria-label`）+ 中间的「{YYYY} 年 {M} 月」（标题元素，`aria-live="polite"`）+「回到本月」（文字按钮，已经是本月时不显示）。到了页面规定的范围尽头，按钮禁用。
- **一周从周一开始**。只画这个月的日子；月初月末的空位是空白格，不显示相邻月的日子。
- **大月历的格子**：七列 `repeat(7, minmax(0, 1fr))`，格子最小高度是 `table-row-height` 的两倍，内边距 `space-1` / `space-2`，格子之间 `border-default`；底 `bg-surface`。第一行是「日」（`font-size-sm`，`text-secondary`，等宽数字）和这一天的标记；下面的内容由页面给，每行单行省略。
- **今天**：「日」用 `font-weight-bold` + `text-primary`，后面跟文字「今天」。**不只靠圈或底色**。「今天」是页面给的日期（按业务的时区），不是浏览器的今天。
- **选中**：格子底 `bg-selected`；一段日期的起点、终点两格第一行另有文字「起」「止」（`text-link`，`font-weight-medium`；只有一天时写「起止」）。选中的范围同时写在月历上方的**选择条**里（「已选 {从} 至 {到}，共 {N} 天」+ 页面给的操作按钮 +「取消选择」；`role="status"`；吸在月历容器顶部）。
- **没有值、值有问题的日子**：图标 + 文字（「没有价格」等，由页面给），底 `bg-subtle`。过去的日子：只把「日」降成 `text-tertiary`，内容不变淡（过去的数据仍然要看得清）。
- **不能选、不能改的日子**（页面规定的范围以外，例如库存日历里过去的日子）：`aria-disabled`；方向键走得到、读得到（读出为什么不能改），但 `Enter`、空格和选择对它们不起作用；拖动选择经过它们时，范围停在最后一个可选的日子。
- **点一天直接改**（库存日历）：这一天的面板里可以放一个小表单；从月历按 `Enter` 后焦点进入面板，面板里 `Esc` 回到月历的那一天。
- **选一段日期**（连续的一段，按日期先后，不是矩形）：
  - 鼠标：按下、拖到另一格、松开；或点一格再 `Shift` + 点另一格。单击 = 选中这一天。
  - 触屏：点起点，再点终点（第一次点后选择条写「再点一天作为结束」）。
  - 键盘：见下。
- **键盘**（`role="grid"`；整个月历只有一个 Tab 停靠点——当前那一天，其余 `tabindex="-1"`）：

  | 键 | 做什么 |
  | --- | --- |
  | `←` `→` / `↑` `↓` | 前后一天 / 前后一周（走出这个月就换月份） |
  | `Home` / `End` | 这一周的周一 / 周日 |
  | `PageUp` / `PageDown` | 上个月 / 下个月，焦点留在同一个「日」（没有这一日就到月末） |
  | `Enter` | 这一天的主要动作（看明细；小月历里是选中它） |
  | `Shift` + 方向键 | 从当前这一天起扩大或缩小选中的范围 |
  | 空格 | 在起点按一次、走到终点再按一次 = 选中这一段（只按一次 = 只选这一天） |
  | `Esc` | 取消选择（小月历里是关闭面板） |

  月历前面有一段读屏可见的用法说明（`aria-describedby`）。格子 `role="gridcell"`，`aria-selected`；`aria-label` 读出「{M} 月 {D} 日周几，｛今天，｝{内容}」。星期表头 `role="columnheader"`。
- 换月份、换条件时：旧格子留着降到 60% 不透明度 + 容器顶部 2px 进度条；首次加载时格子里的内容是骨架（日期数字是算得出来的，照常显示）。
- **窄屏（< 768px）大月历不画格子**（七列在 320px 里每格 41px，放不下一个金额）：排成**一天一行的列表**，按周分组；每行左边「{日} {周几}」和标记，右边值；整行是按钮。选一段日期用一个「选一段日期」的切换按钮（`aria-pressed`）进入选择状态：点开始的一天、再点结束的一天；选择条吸在屏幕底部。
- **小月历面板**：下拉面板样式（第 3 节；层级 `z-dropdown`），宽 `min(288px, 100% - 16px)`，格子是正方形、只有「日」；键盘同上；可以单选一个日期（选了就关）或多选（点一下选中、再点取消，面板底部「完成」）。它是日期输入（第 27 节）之外**多出来的办法**：日期永远可以直接敲。< 480px 时从底部升起。

## 33. 策略步骤编辑器

一串**按顺序依次生效**的小步骤，每一步是「方向 + 方式 + 数值」时用（调价规则的步骤）。它和可增减的行（第 17 节）的区别：顺序有意义、可以调；而且必须配一段「一步一步算给你看」的试算。

```
怎么调 *
第 1 步   [上调 ▾]  [按比例 ▾]  [     20 ] %              [↑] [↓] [×]
第 2 步   [下调 ▾]  [按金额 ▾]  [  1,000 ] JPY            [↑] [↓] [×]
[+ 加一步]
几步从上到下依次算：后一步在前一步算完的结果上接着算。

                            变化          算完是
基础价                                    JPY 20,000
第 1 步  上调 20%            +4,000       JPY 24,000
第 2 步  下调 JPY 1,000      −1,000       JPY 23,000
取整到 JPY 100                            JPY 23,000
```

- 外层 `<fieldset>` + `<legend>`；步骤是 `<ol>`。每一步一行：「第 {i} 步」（`font-size-sm`，`text-secondary`，固定宽）+ 方向（原生下拉：上调 / 下调）+ 方式（原生下拉：按比例 / 按金额）+ 数值 + 行尾「上移」「下移」「删除」（只有图标的文字按钮，`aria-label` 带步骤号）。
- **正负号不让人敲**：数值只填正数，方向由下拉决定；提交时由页面换成带正负号的数。界面上的词是「上调 / 下调」。
- 数值：按比例是输入框 + 后缀「%」（最多两位小数，`inputmode="decimal"`）；按金额是金额输入（第 29 节）。换方式时数值清空（20% 和 20 日元不是一回事）。
- 「加一步」（次要按钮，`sm`，带加号）；到上限禁用，旁边写「最多 {N} 步」。只剩一步时删除禁用，`title`「至少保留一步」。
- 排序只靠「上移」「下移」（做法同第 26 节：焦点跟着这一步走，`Alt` + `↑` / `↓`，`role="status"` 播报「第 2 步现在是第 1 步」）。
- 步骤下面固定一句说明：几步从上到下依次算，后一步在前一步算完的结果上接着算。
- **试算**（必须有）：一张小表，`<caption>` 视觉隐藏；行 = 基数 → 每一步 → 取整；列 = 步骤、怎么调（文字：「上调 20%」）、变化（带正负号）、算完是多少。金额右对齐、等宽数字。基数从哪来由页面给（一个下拉，可以选真实的值或「自己填一个数」；**不预先放示例数字**，没有基数时表的位置写一句怎么开始）。
  - 表里的每个数都来自业务逻辑包的计算函数，和后端用的是同一个；组件不做任何乘除和取整。
  - 中间结果不取整时照实显示，后面小字「（还没取整）」；最后一行写清怎么取整。
  - 结果有问题（例如不大于 0）的行：圆形叹号 + `danger-text`，下面一行说明怎么改。
  - 表下面一句总结（「{基数} → {结果}，比基础价高 / 低 {差额}」），再一句由页面给的限定说明。
  - `aria-live="polite"`，输入停下 500ms 后更新。
- 出错：某一步数值的错误显示在那一步下面，只标红那一格；整组的错误（一步都没有）显示在整组下面。
- 只读：步骤显示成文字（「第 1 步：上调 20%」），试算照常（换基数不改数据）。
- 窄屏（< 480px）：每一步三行——「第 {i} 步」+ 行尾三个按钮；方向、方式两个下拉等分一行；数值撑满一行。试算不用表格：每一步一块，第一行「第 1 步　上调 20%」，第二行右对齐「+4,000　→　JPY 24,000」。

## 34. 星期选择

选「每周的哪几天」时用。

```

- 七个可以多选的切换按钮，周一在最左。`role="group"` + `aria-label`（「每周的哪几天」）；每个是 `<button aria-pressed>`，可见文字「一」到「日」，`aria-label`「周一」到「周日」。

- 旁边可以有快捷的文字按钮（「工作日」「周末」）：点了把对应的几天设成选中，其余不动。

## 35. 文件选择与上传

让人交一个文件给系统时用（导入价格、导入库存；以后的凭证照片、资质证件）。

```
┌ - - - - - - - - - - - - - - - - - - - - - - - - ┐
   [↑]  把 .xlsx 文件拖到这里，或  [选择文件]
        只收 .xlsx，最大 1 MB
└ - - - - - - - - - - - - - - - - - - - - - - - - ┘

prices-2026-10.xlsx · 48 KB   [▓▓▓▓▓▓░░░░] 正在检查…   取消
```

- **真正起作用的是原生的 `<input type="file">`**（视觉隐藏但可以聚焦，带 `accept`）；「选择文件」是它的 `<label>`，画成次要按钮。拖放只是多出来的办法，不能是唯一的办法。
- **选择区**：虚线边框 1px `border-strong`，圆角 `radius-lg`，底 `bg-surface`，内边距 `space-6`，内容居中；一个 20px 上传图标（`text-tertiary`）、一句话和按钮、下面一行限制说明（`font-size-sm`，`text-tertiary`：收什么类型、最大多大——**限制写在选之前，不等出错了才说**）。
  - 拖着文件经过时：底 `bg-selected`，边框换成实线 `border-focus`，那句话换成「松手就开始」。只在拖的是文件时才变。
  - 键盘聚焦在文件输入框上时，聚焦环画在「选择文件」按钮上。
  - 触屏和 < 768px：不写「拖到这里」，只有按钮（撑满）和限制说明。
- **选了以后页面先自己查**（类型按扩展名、大小、是不是空文件、是不是只有一个），不合格的不上传，在选择区下方用出错样式写清「哪个文件、为什么、怎么办」（`role="alert"`）。出错文字由页面给。
- **每次选完都把文件输入框清空**，这样改好以后再选同名文件也会触发。
- 选了就开始还是另点一次「上传」，由页面定；选了就开始时，限制说明里要写明接下来会发生什么（「传上来以后先检查，不会改动任何东西」）。
- **进行中**：选择区换成一行——文件图标 + 文件名（`overflow-wrap: anywhere`）+ 大小（`text-tertiary`）+ 进度条 + 进行时的文字 +「取消」（文字按钮）。
  - 进度条：高 `space-1`，底 `bg-subtle`，已完成的部分 `primary`，圆角 `radius-full`；`role="progressbar"`，知道比例时带 `aria-valuenow`，不知道时（传完了在等服务器处理）是来回移动的一段（设置了「减少动态效果」时静止，只靠文字「正在检查…」）。
  - 取消 = 中止请求，回到选择区，并写一行「已取消，没有改动任何东西。」
  - 开始、取消、完成各用 `role="status"` 说一句。
- **文件大小的写法**：不到 1 MB 写 KB 取整（`48 KB`），不小于 1 MB 写一位小数（`1.2 MB`）；1 MB = 1,048,576 字节（和后端的上限同一个算法）。
- 失败（服务器说文件读不了、网络不通）：回到选择区，下方危险提示条写原因和怎么办；网络的问题给「重试」（用同一个文件，不用重新选）。
- 页面拿着用户选的那个文件对象，后面要再传一次时直接用它；如果浏览器说读不了了（文件在磁盘上被改过或移走），按「文件变了，请重新选择」处理。
- 只读、没有权限的角色不显示这个组件。

## 36. 导入结果

把一份文件逐行检查完以后，告诉人「能不能导入、各有多少、哪一行哪一格有什么问题」时用。三部分，从上到下：**总结提示条 → 各类行数 → 逐行表**；下面是「换一个文件」和「确认」两个按钮。

```
┌ ! 现在不能导入：有 2 行出错、1 行冲突 ───────────────────────┐
│ 只要有一行有问题，整份都不会写入。……                          │
└─────────────────────────────────────────────────────────────┘
共 42 行：  [新增 18]  [修改 12]  [没变 9]  [出错 2]  [冲突 1]        ☑ 只看有问题的
┌──────────┬────────┬──────────────┬──────────────────────────────┐
│ Excel 行号│ 结果    │ 这一行是什么   │ 说明                          │
│ 7        │ ! 出错  │ —            │ F7  基础价：日元金额不能有小数   │
└──────────┴────────┴──────────────┴──────────────────────────────┘
```

- **文件那一行**（最上面）：文件名 · 大小 · 检查的时刻（`HH:mm`），右边「换一个文件」。让人确认看的是哪一份的结果。
- **总结提示条**（第 8 节）：三种——可以导入（`success`）、有问题不能导入（`danger`，`role="alert"`）、没有要导入的内容（`info`）。标题一句话回答「能不能」，正文说数字和下一步。「整份一起成功或一起不写」必须写在有问题的那一种里。结果出来后焦点移到这个标题。
- **各类行数**：一行，前面「共 {N} 行：」，后面每一类一个切换按钮（`aria-pressed`；次要按钮 `sm` 的样子，选中时底 `primary-subtle`、字 `text-link`，文字前加对勾）：类别名 + 数字（等宽）。0 的也显示（不能点）。点一类 = 逐行表只看这一类；再点一次取消。放不下自动换行，每个按钮内部不折行。
- **「只看有问题的」**复选框：有问题时默认勾着；勾着时表格下方写「另有 {N} 行没有问题，没有列出」。一行有问题的都没有时不显示它。
- **逐行表**：第 5 节的表格，`<caption>` 视觉隐藏（「检查结果，共 {N} 行」）；容器最高 `60dvh`，自己滚动，表头吸顶。列：
  - 行号——**用户在表格软件里看到的行号**（等宽，`<th scope="row">`），列头写明「Excel 行号」。
  - 结果——图标 + 文字，每一类图标形状不同：新增（加号）、修改（笔）用 `info-text`；没变（短横线）`text-tertiary`；出错（圆形叹号）`danger-text`；冲突（三角）`warning-text`。不给整行铺底色。
  - 这一行是什么——一句给人看的话，让人认得出是哪一条；认不出时「—」。
  - 说明——每个问题一行：**单元格的位置**（等宽，`font-weight-medium`，可以选中复制；如 `F7`）+ 列名 + 一句写清「错在哪、怎么改」的话。没有问题的行空着。
  - 有问题的行，行首 3px 竖条：出错 `danger-solid`。冲突不加竖条（文字和图标已经够了；通用背景上没有可用的警告色实底）。
- 顺序按行号，不提供排序。一次全部画出（上限由业务定在几百行）。
- **按钮**：「换一个文件」（次要）和确认的那个主按钮；主按钮不能点时用 `aria-disabled`，旁边写原因。主按钮上方固定一行说明：检查没有改动任何东西；确认时还会再检查一次。

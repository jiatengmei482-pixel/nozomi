# 组件规范

所有数值都引用 [`tokens.css`](./tokens.css) 的令牌。每个组件写四件事：尺寸、各状态、手机下怎么办、键盘与无障碍。

通用约定：

- 聚焦环写法见 `01-tokens.md` 第 5 节，所有可聚焦元素都要有。
- 悬停样式只在 `@media (hover: hover)` 下生效，避免触屏点完后「粘住」。
- 颜色过渡 `var(--duration-fast)`。
- 可点击区域最小 24×24px；触屏下控件高度由令牌自动变为 44px。
- 优先用原生元素（`<button>`、`<a>`、`<input>`、`<select>`、`<dialog>`、`<table>`），它们自带键盘行为和语义。只有原生元素做不到时才自己拼，并补齐 ARIA。

## 1. 按钮

| 类型 | 用在哪 | 默认 | 悬停 | 按下 |
| --- | --- | --- | --- | --- |
| 主按钮 | 一个区域里最该点的那一个（保存、登录、确认派车）。**每个区域最多一个** | 底 `primary`，字 `on-primary` | 底 `primary-hover` | 底 `primary-active` |
| 次要按钮 | 其他操作（取消、导出、筛选） | 底 `bg-surface`，边框 `border-strong`，字 `text-primary` | 底 `bg-hover` | 底 `bg-subtle` |
| 文字按钮 | 表格行内操作、不重要的操作 | 无底无边，字 `text-link` | 底 `primary-subtle` | 底 `bg-selected` |
| 危险按钮 | 不可恢复的操作的最终确认（停用、删除、声明无法履约） | 底 `danger-solid`，字 `on-danger` | 底 `danger-solid-hover` | 底 `danger-solid-active` |

- 尺寸：高 `control-height-sm / md / lg`；左右内边距 `space-3`（sm 为 `space-2`，lg 为 `space-4`）；字号 `font-size-md`（lg 为 `font-size-lg`）；字重 `font-weight-medium`；圆角 `radius-md`；最小宽度 64px。文字不换行。
- 图标 + 文字：图标 16px，间距 `space-1`。只有图标的按钮宽高相等，必须有 `aria-label`，并在悬停和聚焦时显示同样文字的气泡提示。
- **禁用**：底 `bg-disabled`，字 `text-disabled`，无边框，`cursor: not-allowed`。用原生 `disabled`。按钮因为缺少条件而禁用时，旁边要有文字说明原因（如「请先选择司机」），不能只是灰掉。
- **加载中**（已点击，等待结果）：保持原来的颜色和宽度，文字前加 16px 转圈，文字改成进行时（「保存中…」「正在登录…」）；设 `aria-busy="true"`，不响应再次点击。不要用 `disabled`，否则焦点会丢。
- 排列：一组按钮间距 `space-2`。桌面端主按钮在最右；对话框和表单底部同此。手机下（< 480px）表单和对话框底部的按钮各占一行、撑满宽度，主按钮在最上。
- 危险操作的入口（列表里的「停用」）用次要按钮或文字按钮加 `danger-text` 文字色，只有二次确认对话框里的最终确认才用危险按钮。
- 键盘：Tab 聚焦，Enter 和空格触发。跳转页面用 `<a>`，执行操作用 `<button>`，不要混用；`<button>` 一律写明 `type`。

## 2. 输入框

- 尺寸：高 `control-height-md`（登录页、官网、司机 H5 用 `lg`）；左右内边距 `space-3`；字号 `control-font-size`；圆角 `radius-md`；宽度撑满所在栅格列。多行文本框最少 3 行，可纵向拉伸，不可横向拉伸。
- 默认：底 `bg-surface`，边框 1px `border-strong`，字 `text-primary`，占位文字 `text-tertiary`。
- 悬停：边框 `text-secondary`。
- 聚焦：聚焦环 `border-focus`，`outline-offset: -1px`。
- 出错：边框 2px `danger-solid`（内边距相应减 1px，避免抖动）；下方显示出错文字（见第 4 节）。`aria-invalid="true"`。
- 禁用：底 `bg-disabled`，字 `text-disabled`，边框 `border-default`。
- 只读：底 `bg-subtle`，字 `text-primary`，边框 `border-default`，可以选中复制，可以聚焦。
- 前后缀（币种代码、单位「分钟」「公里」、显示密码按钮）放在输入框内部两端，字色 `text-secondary`，不能被输入内容盖住。
- 占位文字只用来举格式的例子，不能代替标签。
- 按内容设置 `type`、`inputmode`、`autocomplete`：邮箱 `type="email"`，电话 `type="tel"`，金额和数量 `inputmode="decimal"` 或 `"numeric"`。**金额和数量不用 `type="number"`**（滚轮会误改数值，且不同浏览器对小数处理不一致）。
- 密码框右侧有「显示密码 / 隐藏密码」图标按钮，`aria-pressed` 表示当前状态。

## 3. 选择器

| 场景 | 用什么 |
| --- | --- |
| 选项 ≤ 10 个、不需要搜索 | 原生 `<select>`，外观与输入框一致，右侧 16px 下箭头 |
| 选项多、需要搜索或多选（城市、机场、司机、车辆、车型组） | 组合框：输入框 + 下拉面板 |
| 2–4 个互斥选项且需要一眼看到全部（品类、计费方式） | 单选按钮组 |
| 开 / 关，立即生效 | 开关 |
| 开 / 关，随表单一起保存 | 复选框 |

**组合框**

- 面板：底 `bg-surface`，边框 `border-default`，圆角 `radius-lg`，阴影 `shadow-md`，层级 `z-dropdown`；最大高度 320px，内部纵向滚动；宽度不小于输入框，不超出视口（距屏幕边缘至少 `space-2`）。
- 选项：高 `control-height-md`；悬停或键盘高亮 `bg-hover`；已选中 `bg-selected` 并在右侧显示对勾（不只靠底色）。
- 多选：已选项以可删除的小标签显示在输入框内，超过一行时换行增高，不横向溢出。
- 状态：加载中显示「加载中…」；无匹配显示「没有匹配的选项」；加载失败显示「加载失败」和「重试」。
- 手机（< 480px）：面板改为从底部升起的面板，宽度撑满，最高占屏幕 70%。
- 键盘：↓ 打开；↑↓ 移动高亮；Enter 选中；Esc 关闭并把焦点留在输入框；输入文字即筛选。
- 无障碍：输入框 `role="combobox"`、`aria-expanded`、`aria-controls`、`aria-activedescendant`；面板 `role="listbox"`；选项 `role="option"` + `aria-selected`。

**复选框、单选、开关**

- 方框和圆点 16×16px，边框 `border-strong`；选中后底 `primary`，对勾 `on-primary`。开关 36×20px，关闭时底 `border-strong`，打开时底 `primary`，滑块 `bg-surface`。
- 文字标签在右侧，间距 `space-2`，点文字也能切换（用 `<label>` 包住）。整行可点击区域高度不小于 `control-height-md`。
- 开关旁边必须有文字写出当前状态（「已启用」/「已停用」），不能只靠颜色和滑块位置。
- 用原生 `<input type="checkbox">` / `<input type="radio">`；开关加 `role="switch"`。单选组用 `<fieldset>` + `<legend>`，↑↓←→ 在组内切换。

## 4. 表单布局与校验提示

**布局**

- 标签在输入框**上方**，左对齐，字号 `font-size-sm`，字重 `font-weight-medium`，字色 `text-secondary`，与输入框间距 `space-1`。不用左右排列的标签（手机放不下，中日英长度差别大）。
- 必填项在标签后加红色星号（`danger-text`，`aria-hidden="true"`），同时输入框设 `required`。一个表单里大部分都必填时，反过来只在选填项的标签后写「（选填）」。
- 帮助说明在输入框下方，`font-size-sm`，`text-tertiary`，间距 `space-1`。出错时，出错文字显示在帮助说明的位置上方，帮助说明保留。
- 字段之间纵向间距 `space-4`。分组之间 `space-8`，每组有一个标题（`font-size-lg`，`font-weight-bold`）。
- 栏数：< 768px 单栏；≥ 768px 最多两栏，栏间距 `space-4`。长文本、地址、多选占整行。表单最大宽度 `layout-form-max-width`。
- 底部操作区：与最后一个字段间距 `space-6`。长表单的操作区吸在视口底部（底 `bg-surface`，上边线 `border-default`，层级 `z-sticky`）。
- 离开未保存的表单时弹确认：「有未保存的修改，确定离开吗？」

**校验**

- 时机：字段第一次失去焦点时校验；出过错的字段在输入过程中实时重新校验；点提交时全部校验。不在用户刚开始输入时就报错。
- 字段出错：输入框换成出错样式；下方显示出错文字，`font-size-sm`，`danger-text`，前面带 14px 的警示图标（图标 + 文字，不只靠红色）。出错文字的元素用 `aria-describedby` 关联到输入框。
- 提交时有错：焦点移到第一个出错的字段，并滚动到可见位置。字段超过一屏的表单，另在表单顶部放一条危险提示条：「有 N 处需要修改」，列出字段名，点字段名跳到对应字段。
- 后端返回的字段错误显示在对应字段下；不属于某个字段的错误显示在表单顶部的提示条里。
- 出错文字写清「错在哪 + 怎么改」：写「请输入邮箱」「结束日期不能早于开始日期」，不写「输入无效」「参数错误」。
- 提交中：提交按钮进入加载态，其他字段设为只读，直到有结果。提交失败后保留用户已填的所有内容。

## 5. 表格

- 容器：底 `bg-surface`，边框 `border-default`，圆角 `radius-lg`，`overflow-x: auto`。**表格只在自己的容器里横向滚动，页面本身不滚动。** 容器加 `tabindex="0"`、`role="region"`、`aria-label`（表格名称），让键盘用户能用方向键横向滚动。
- 表头：底 `bg-subtle`，字号 `font-size-sm`，字重 `font-weight-medium`，字色 `text-secondary`，高 `table-row-height`，不换行。纵向滚动时吸顶（`z-sticky`）。
- 行：最小高度 `table-row-height`；单元格内边距上下 `space-2`、左右 `space-3`；行间用 `border-default` 分隔，不用斑马纹；悬停 `bg-hover`；选中 `bg-selected`。
- 对齐：文字左对齐；金额和数量右对齐并用等宽数字；状态徽标左对齐；操作列在最右。表头与内容对齐方式一致。
- 列宽：编号、日期、金额、状态、操作不换行；名称、地址等长文字最多两行，超出用省略号，完整内容放在 `title` 和详情页里。
- 行内操作：最多 2 个文字按钮，其余收进「更多」菜单。
- 排序：可排序的表头是一个 `<button>`，右侧有箭头标出方向；所在 `<th>` 设 `aria-sort`。
- 多选：首列复选框，表头的复选框表示全选当前页（部分选中时为半选状态）。选中后在表格上方显示「已选 N 项」和批量操作。
- 需要置顶提醒的行（如超过派车截止时间未派车）：行首加 3px `danger-solid` 竖条，并且状态列的徽标文字写明原因（「超时未派车」）。不把整行染红。
- 语义：用真正的 `<table>`、`<thead>`、`<th scope="col">`。整行可点进详情时，第一列的编号是一个 `<a>`，不要只给 `<tr>` 绑点击。

**手机宽度（< 768px）下的两种呈现，按表格用途选一种：**

| 方式 | 用于 | 做法 |
| --- | --- | --- |
| A. 容器内横向滚动（默认） | 列多、主要在桌面用的表（价格规则、对账明细、审计日志、调用日志） | 表格保持原样，容器横向滚动；第一列（编号或名称）固定在左侧（`position: sticky`，底 `bg-surface`，右侧加 `border-default`）；容器右边缘在可继续滚动时显示 16px 的渐隐，提示还有内容 |
| B. 卡片列表 | 会在手机上处理的表（订单列表、派车、工单、司机、车辆） | 每行变成一张卡片：第一行是编号 + 状态徽标（两端对齐），接着是 2–4 个关键字段（「标签：值」逐行排），最下面是操作按钮。卡片间距 `space-2`，内边距 `space-4`。其余字段进详情页看 |

每个页面的说明里要写明用 A 还是 B；用 B 时列出卡片上保留哪几个字段。

**筛选条**：在表格上方，控件用 `sm` 尺寸，间距 `space-2`，放不下自动换行。< 768px 时只保留搜索框和一个「筛选」按钮，其余条件收进从底部升起的面板；按钮上显示已生效的条件数（「筛选 · 2」）。已生效的条件在表格上方以可删除的小标签列出，并提供「清空筛选」。

## 6. 分页

- 位置：表格容器下方，间距 `space-3`。左侧「共 N 条」，右侧是每页条数选择（20 / 50 / 100，默认 20）和翻页按钮。
- 翻页：「上一页」「下一页」+ 页码，都是 `sm` 尺寸的次要按钮。页码最多显示 7 个，多出的用「…」代替。当前页底 `primary-subtle`、字 `text-link`、`aria-current="page"`。
- 第一页时「上一页」禁用，最后一页时「下一页」禁用。
- 手机（< 480px）：只显示「上一页」「第 X / Y 页」「下一页」；「共 N 条」移到上一行。
- 翻页后表格滚回顶部，焦点移到表格容器。筛选条件、页码、每页条数写进网址参数，刷新和分享链接后保持不变。
- 外层用 `<nav aria-label="分页">`。
- 后端用游标分页的列表（没有总页数）：只显示「上一页」「下一页」，不显示页码和总条数。

## 7. 标签与状态徽标

**状态徽标**

- 尺寸：高 22px；内边距 `space-0-5` / `space-2`；字号 `font-size-xs`；字重 `font-weight-medium`；圆角 `radius-sm`；不换行。
- 样式：底 `{状态}-bg`，字 `{状态}-text`，边框 1px `{状态}-border`。文字前有一个 6px 圆点，颜色同文字。
- **文字必须写出状态名**。同一个页面里两种状态即使颜色相同，文字也必须不同。
- 颜色按含义选，同一个状态在所有页面用同一个颜色：

| 颜色 | 含义 | 需求文档里出现的状态（举例） |
| --- | --- | --- |
| `neutral` | 还没开始、已结束且无需关注 | 草稿、未上架、已下架、已停用、已取消 |
| `info` | 正在进行、等待对方 | 待派车、已派车、已出发、已到达、已接到客人、审核中 |
| `success` | 正常结束、可用 | 已上架、已完成、已通过、在职、可用 |
| `warning` | 有时限、快到期、需要留意 | 即将到期、派车截止前提醒、维修 |
| `danger` | 已超时、失败、被拒绝 | 超时未派车、已到期、已拒绝、投递失败 |

每个业务对象的「状态 → 颜色 → 显示文字」对照表写在一个地方（前端的一个常量文件），页面不各自决定。新增状态时由美工确定颜色。

**标签**（表示属性，不表示状态：品类、车型组、语言、「新车」「金牌司机」）

- 尺寸同状态徽标；底 `bg-subtle`，字 `text-secondary`，无边框，无圆点。
- 可删除的标签（多选的已选项、已生效的筛选条件）右侧有 × 按钮，`aria-label="移除 {名称}"`。

## 8. 提示条与 Toast

**提示条**（留在页面里，直到情况改变或用户关闭）

- 用于：页面或表单级别的错误、需要用户知道的持续状态（如「资质审核通过前不能上架」）。
- 样式：底 `{状态}-bg`，边框 `{状态}-border`，圆角 `radius-md`，内边距 `space-3`；左侧 16px 图标（色 `{状态}-text`），标题 `font-weight-medium` + `{状态}-text`，正文 `text-primary`，字号 `font-size-md`。可带一个文字按钮（「重试」「去处理」）。
- 四种：`info`、`success`、`warning`、`danger`，各自用固定的图标（信息、对勾、三角警示、圆形叹号）。图标形状不同，不只靠颜色。
- 位置：页面级放在页面标题下方；表单级放在表单顶部。
- 无障碍：出错和警告用 `role="alert"`（出现时立即读出）；信息和成功用 `role="status"`。

**Toast**（短暂出现，自动消失）

- 只用于确认「刚才的操作成功了」（「已保存」「已复制」「已派车」）。**出错不用 Toast**：错误用提示条或字段提示，留在原地直到解决。
- 样式：底 `bg-inverse`，字 `text-inverse`，圆角 `radius-md`，阴影 `shadow-md`，内边距 `space-3` / `space-4`，层级 `z-toast`；最大宽度 `min(360px, 100% - 32px)`。
- 位置：桌面端顶部居中，距顶 `space-4`；手机端底部居中，距底 `space-4` 再加上 `env(safe-area-inset-bottom)`。
- 停留 4 秒；鼠标悬停或键盘聚焦时暂停计时。带「撤销」按钮的停留 8 秒。同时最多显示 3 条，新的在下方。
- 无障碍：放在一个始终存在的 `role="status"` + `aria-live="polite"` 区域里；不抢焦点。

## 9. 对话框

- 用于：二次确认、不离开当前页的简短表单（一屏以内）。更长的内容用单独的页面。
- 尺寸：宽 `min(480px, 100% - 32px)`（确认）或 `min(640px, 100% - 32px)`（表单）；最大高度 `100dvh - 64px`，超出时只有正文区域纵向滚动，标题和底部按钮固定。
- 样式：底 `bg-surface`，边框 `border-default`，圆角 `radius-xl`，阴影 `shadow-lg`，内边距 `space-5`，层级 `z-dialog`；遮罩 `bg-overlay`，层级 `z-overlay`。
- 结构：标题（`font-size-xl`，`font-weight-bold`）+ 右上角关闭按钮（`aria-label="关闭"`）；正文；底部按钮右对齐，主按钮在最右。
- 手机（< 480px）：贴底显示，宽度撑满，只有上方两个角有圆角；底部按钮各占一行，底部留出 `env(safe-area-inset-bottom)`。
- **危险操作的确认**：标题直接写要做的事（「停用这个司机？」）；正文写清后果（会影响什么、能不能恢复、要扣多少钱）；确认按钮用危险按钮，文字写动作本身（「停用」），不写「确定」；取消按钮写「取消」。默认焦点落在「取消」上。
- 打开时：焦点移到对话框内第一个可操作的元素（危险确认时是「取消」）；Tab 只在对话框内循环；背景内容不可操作、不可滚动。
- 关闭：Esc、关闭按钮、取消按钮。点遮罩可以关闭确认类对话框；**有表单的对话框点遮罩不关闭**，避免误丢内容。关闭后焦点回到打开它的那个按钮。
- 实现：用原生 `<dialog>` 的 `showModal()`，或 `role="dialog"` + `aria-modal="true"`；`aria-labelledby` 指向标题。
- 不在对话框里再开对话框。

## 10. 导航

后台框架的尺寸见 `03-layout.md`。

**侧边栏**

- 宽 `layout-sidebar-width`；底 `bg-surface`，右边线 `border-default`；内部可纵向滚动。
- 顶部是品牌名 NOZOMI 和当前后台的名称（「运营后台」或「供应商后台」）。
- 菜单项：高 36px（触屏 44px）；左右内边距 `space-3`；16px 图标 + 文字，间距 `space-2`；字号 `font-size-md`；字色 `text-secondary`；圆角 `radius-md`。
  - 悬停：底 `bg-hover`，字 `text-primary`。
  - 当前页：底 `primary-subtle`，字 `text-link`，字重 `font-weight-medium`，左侧 3px `primary` 竖条；`aria-current="page"`。
- 二级菜单：一级项可展开，子项缩进 `space-6`；一级项是 `<button aria-expanded>`。当前页所在的分组默认展开。最多两级。
- 只显示当前角色有权限的菜单；没有权限的不显示（不是置灰）。
- 待办数量：菜单项右侧的数字徽标（底 `danger-bg`，字 `danger-text`，`radius-full`），超过 99 显示「99+」，并在 `aria-label` 里读出（「工单，3 条待处理」）。
- ≥ 1024px：常驻显示。可以收起成 `layout-sidebar-width-collapsed` 宽，只剩图标，悬停和聚焦时用气泡显示名称；收起状态存在浏览器本地。
- < 1024px：默认不显示。点顶栏左侧的菜单按钮后从左侧滑入，宽 `min(280px, 100% - 56px)`，层级 `z-sidebar`，阴影 `shadow-lg`，后面是遮罩。此时它是一个模态面板：焦点限制在内部；Esc、点遮罩、点任一菜单项后关闭；关闭后焦点回到菜单按钮。
- 外层 `<nav aria-label="主菜单">`。

**顶栏**

- 高 `layout-topbar-height`；底 `bg-surface`，下边线 `border-default`；吸顶，层级 `z-topbar`。
- 左侧：菜单按钮（仅 < 1024px 显示，`aria-label="打开菜单"`，`aria-expanded`）、面包屑。
- 右侧：主题切换（跟随系统 / 亮色 / 暗色）、当前账号（姓名 + 角色，点开是下拉菜单：个人设置、退出登录）。
- < 768px：面包屑只显示当前页名称；账号只显示头像或姓名首字，角色名收进下拉菜单。
- 平台员工「以某租户身份查看」供应商后台时，顶栏下方加一条不能关闭的警告提示条，写明正在查看的租户名称和「只读」，并提供「退出查看」按钮。

**跳到正文**：页面第一个可聚焦元素是「跳到正文」链接，平时不可见，聚焦时显示在左上角，跳到 `<main>`。

**面包屑**：`font-size-sm`，层级之间用「/」分隔；前面几级是链接（`text-link`），最后一级是当前页（`text-primary`，`aria-current="page"`）。外层 `<nav aria-label="当前位置">`。

**页签**（一个页面里的平级分区，如商品的「基础信息 / 服务规则 / 价格规则 / 库存 / 商品详情」）：高 40px；当前项字 `text-link`、下方 2px `primary` 横线；其余字 `text-secondary`。放不下时页签条自己横向滚动，不换行，也不撑宽页面。`role="tablist"` / `role="tab"` / `role="tabpanel"`，←→ 切换。

## 11. 空状态

- 位置：在本该出现内容的区域里居中（表格就在表格容器内，表头保留），上下留白 `space-10`。
- 内容：一句标题（`font-size-lg`，`font-weight-medium`，`text-primary`）+ 一句说明（`font-size-md`，`text-secondary`，最多两行）+ 最多一个按钮。不用插图。
- 区分三种情况，文案不能混用：

| 情况 | 标题怎么写 | 说明怎么写 | 按钮 |
| --- | --- | --- | --- |
| 还没有任何数据 | 「还没有{对象}」 | 一句话说明这个东西是干什么的、下一步做什么 | 有新建权限时放主按钮「新建{对象}」；没有权限时不放 |
| 有数据，但筛选或搜索后没有结果 | 「没有符合条件的{对象}」 | 「换个条件试试，或清空筛选。」 | 次要按钮「清空筛选」 |
| 没有权限看 | 「你没有权限查看这里」 | 「需要的话，请联系管理员开通。」 | 无 |

- 不显示假数据、示例行来填充空白。

## 12. 加载状态

| 场景 | 做法 |
| --- | --- |
| 页面或区域首次加载 | 骨架屏：按最终布局画出灰块（底 `bg-subtle`，圆角 `radius-sm`）。表格画表头 + 5 行灰条。加载完成后布局不跳动 |
| 已有内容，正在刷新（翻页、改筛选） | 保留旧内容并降到 60% 不透明度，区域顶部显示 2px 的 `primary` 进度条；不清空成骨架屏 |
| 按钮触发的提交 | 按钮加载态（见第 1 节） |
| 下拉面板、小区域 | 16px 转圈 + 「加载中…」 |

- 请求在 300ms 内返回时不显示任何加载样式，避免闪一下。
- 超过 10 秒仍未返回：在加载区域里加一行「加载时间比平时长，请稍等，或刷新页面重试。」
- 无障碍：加载中的区域设 `aria-busy="true"`；骨架屏 `aria-hidden="true"`，另放一个只给读屏的「加载中」（`role="status"`）。
- 转圈动画在用户设置了「减少动态效果」时不转，改为静止图标 + 文字。

## 13. 错误状态

| 情况 | 显示在哪 | 文案 | 操作 |
| --- | --- | --- | --- |
| 某个区域加载失败（列表、卡片） | 该区域内，版式同空状态，图标用圆形叹号（`danger-text`） | 标题「加载失败」；说明「请检查网络后重试。」 | 次要按钮「重试」 |
| 提交失败（网络问题、服务器错误） | 表单顶部的危险提示条 | 「保存失败，请稍后重试。你填写的内容还在。」 | 用户再点一次提交 |
| 提交被业务规则拒绝 | 对应字段下方，或表单顶部的危险提示条 | 用后端返回的中文说明，写清原因和怎么办 | 视情况 |
| 登录已过期 | 跳到登录页，登录页显示信息提示条 | 「登录已过期，请重新登录。」 | 登录后回到原来的页面 |
| 没有权限（403） | 内容区 | 同空状态的「没有权限」 | 无 |
| 页面不存在（404） | 内容区（保留侧边栏和顶栏） | 标题「找不到这个页面」；说明「它可能已被删除，或链接有误。」 | 主按钮「回到首页」 |
| 整个页面出错（前端异常、服务不可用） | 整页，居中 | 标题「页面出了点问题」；说明「请刷新重试。如果一直这样，请把下面的编号发给管理员。」 | 主按钮「刷新页面」 |

- 后端返回了请求编号时，在错误说明下方用等宽字体显示「编号：{请求编号}」，并提供「复制」按钮，方便用户报给管理员。
- 不向用户显示状态码、堆栈、英文原始报错、内部字段名。
- 一处出错不影响页面其他部分：侧边栏、顶栏和其他卡片照常可用。
- 出错后保留用户已经填写的内容和筛选条件。

## 14. 气泡提示

- 只放补充信息（图标按钮的名称、被截断文字的全文、时间的另一种时区表示）。必须读到的信息不放在气泡里。
- 样式：底 `bg-inverse`，字 `text-inverse`，`font-size-sm`，圆角 `radius-sm`，内边距 `space-1` / `space-2`，最大宽度 240px，层级 `z-tooltip`。
- 悬停 400ms 后出现；键盘聚焦时立即出现；Esc 关闭；鼠标移到气泡上时不消失。
- 触屏没有悬停：需要在手机上看到的内容不能只放在气泡里。
- `role="tooltip"`，触发元素用 `aria-describedby` 关联。

## 15. 图标

- 一套线性图标，以内联 SVG 的形式放在代码仓库里，`stroke="currentColor"`，颜色跟随文字。不引用外部图片或图标字体。具体选用哪一套开源图标由前端决定（要求：许可证允许商用、线宽一致、可以只打包用到的图标）。
- 尺寸：16px（正文和按钮里）、20px（顶栏、司机 H5）。
- 装饰性的图标加 `aria-hidden="true"`；单独表达含义的图标必须有文字替代（`aria-label` 或旁边的隐藏文字）。

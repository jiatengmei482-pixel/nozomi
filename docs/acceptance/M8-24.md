## 缺口和建议（不影响通过）

1. 测试环境的 QA 测试供应商停在「申请中」，「已签约时没有开始试运营、显示原因」只能用本机端到端和组件测试证明（见上）。
2. 文案建议：测试供应商「已签约」时，入驻进度第一句仍是通用的「……完成测试单后开始试运营。」，紧接着第二句说它不能开始试运营，读起来略矛盾。可考虑测试供应商时换掉第一句，另开任务处理即可。
3. 区域地图左侧区域列表里每条区域下写的供应商名称没有「（测试）」——设计 §5.5 只要求下拉选项加，符合设计，记录备查。
4. GitHub 上最近一次「Deploy」工作流跑的是 main 的 bde37311；测试环境上能看到本任务的标记和说明，说明协调者说的分支部署确实已上线。
